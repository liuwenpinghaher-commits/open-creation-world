## 0. 现状一句话
核心回路已经不错：画/说 → 感知 → 引导引擎 → "诚实朋友"式回应 → 偶发兑现 → 存作品 → 成长册/报告。个性化、人设、隐私、可写配置都通且有测试（tsc/eslint/vitest 55、真实集成 5、Playwright 7 全绿）。**但加了多孩子、设置、报告之后，冒出一批"功能装了却不闭环/数据会串"的新问题。**

---

## 1. 🔴 业务不闭环 / 功能缺口

### B1 · 纯画画不触发 AI（最致命的体验缺口）
一拍**只能由"说话/打字"触发**（[App.tsx](../src/App.tsx) `handleMic`/`submitTyped` → `runTurn`）。画布的 `store.listen` 只做 `dirty=true`+自动保存，**从不发起一拍**。
→ 一个安静地画、不爱出声的孩子（低龄/内向最常见），**AI 全程沉默**，等于没有陪伴。这与"陪孩子创作"的根本承诺冲突。

### B2 · 多孩子作用域错乱（数据会串、归属会翻转）
- **成长册不按孩子过滤**：`openJournal = listWorks()`（[App.tsx:140](../src/App.tsx#L140)），**列出所有孩子的作品**；而设置里的「报告」是按 `childId` 过滤的——两处口径不一致，老大的成长册里混着老二的画。
- **切孩子不切作品 → 归属翻转**：当前作品指针 `getCurrentId` 是**全局 localStorage**，与孩子无关。家长在设置里切到老二后，孩子继续画的还是**老大那张未关的作品**，下次 `saveNow` 却把它打上**老二的 childId**（[App.tsx:177](../src/App.tsx#L177) 用 `activeChildRef`）→ 作品被错误改主、跨孩子数据污染。

### B3 · 对象定位形同虚设（功能可达性 0）
兑现支持"只动选中的笔触"（`getSelectedShapeIds`），但**儿童工具栏没有"选择"工具**（只有 🖌️🧽↩️🆕📖⚙️，[App.tsx:300-306](../src/App.tsx#L300)）。孩子**没有任何办法选中** → 兑现永远只能动整张画。P1 写了却用不上。

### B4 · 成长报告靠手动触发，不自动（报告基本是空的）
学习故事**只有家长在成长册点「✨生成学习故事」时才生成**（[App.tsx:362](../src/App.tsx#L362)）。不点 → 报告页的 Torrance 趋势、周记、叙事**永远空**。"自动记录孩子成长"的承诺没闭环——创作发生了，但默认不被记录。

### B5 · 已生成的故事刷新后丢显示、会重复调模型
成长册只读**内存** `stories`（[App.tsx:347](../src/App.tsx#L347)），**不加载已持久化的故事**。刷新后内存清空 → "生成学习故事"按钮重现，家长再点会**再调一次 LLM**（`saveStory` 按 `s_${workId}` 覆盖不会重复存，但白花一次模型调用 + 家长以为没生成过）。

## 2. 🟠 架构 / 健壮性

### A1 · AI 对画没有跨拍记忆
`noticed`（AI 对画的观察/理解/猜想）**每拍算完即扔**——不入库、不回传给下一拍。模型每拍重新看一张扁平 PNG，没有"我认识这幅画、记得我们聊过它是龙"的连续感（只靠最近 8 条对话文本兜）。这正是"感觉没头脑"的残留根因之一。

### A2 · 豪华兑现(AnimatedDrawings)抓取无超时
`tryFigureAnimation`（[figure.ts](../src/fulfill/figure.ts)）用普通 `fetch`、**无 AbortController/超时**。家长配了一个慢或卡住的 AD 服务 → **阻塞整拍**，孩子干等到浏览器超时。

### A3 · App.tsx 过重、无编排层测试
~420 行，编排 + 持久化 + 成长册 + 设置入口 + 家庭加载 + 兑现 + 语音 + 故事全挤在一个组件；`runTurn` 的分支（dirty/fulfill/figure/并行/隐私）**无单测**，只有纯模块单测 + e2e。回归风险集中在这个大文件。

### A4 · 方言/语言与音色不一致
`language` 偏好（方言/双语）只进**文本提示词**，但 qwen-tts 音色固定（Cherry，普通话）。结果："让 AI 用粤语聊"但实际**念出来还是普通话**——设置生效了一半，不闭环。

### A5 · 全语音无文字兜底（坏 key/静音环境直接失能）
去文字后，若 TTS 持续失败（密钥错/额度尽），孩子**只看到 hint、听不到任何内容、也没有文字可看**；`🔊再听一次` 重试的还是同一个会失败的 TTS。对听障/静音环境/配置出错是硬失能。（注：全语音是你明确要的，此处仅标robustness缺口，建议保留一个"出问题时临时显示文字"的降级。）

## 3. 🟡 体验 / 验证 / 安全

- **E1 多孩子日常切换重**：谁在玩只能家长进设置（过家长门）改，儿童端无切换；多孩子家庭每天换人很麻烦。
- **E2 首启无建档引导**：没有孩子档案时静默用默认（神笔/7岁），不引导家长建档；个性化/报告因此对新用户默认不生效。
- **S1 配置密钥明文落 `config.json`**（已 gitignore，家用可接受，但明文存盘）。
- **S2 运行时 API 失败只回笼统 500**，家长除设置里"测试连接"外无运行时诊断/重试提示。
- **V1 产品核心假设未经真人验证**：孩子是否因"被好好提问 + 诚实朋友"而一画再画——仍只有本地信号，无真机/真孩子观测。**这才是最大的"未闭环"。**
- **H1 系统卫生**：后台残留 8 个 `codegraph serve --mcp` 守护进程（非 app 问题）。

## 4. 已闭环 / 做得好的（平衡视角）
- 主回路（单主体、有说话）质量好；引导引擎（PEER/CROWD/四维轮换/节奏自适应）+ 个性化（childContext→prompt + nextMove 加权）+ **诚实朋友人设（可调主见，反 sycophancy）**都通且实测优。
- 防假兑现、隐私模式、多作品持久化、可写配置（密钥掩码）、成长册聚合 —— 闭环且有测试覆盖。

## 5. 整改优先级建议

| 序 | 问题 | 价值 | 方向 |
|---|---|---|---|
| 1 | B1 纯画不触发 | 最高 | 孩子画完停顿(防抖)→自动发起一拍(仅凭画、无语音也回应)；或加"画好了"按钮 |
| 2 | B2 多孩子串/翻转 | 高·正确性 | 成长册按 childId 过滤；切孩子=保存当前→新建/切到该孩子的作品；currentWorkId 改为 per-child |
| 3 | B4+B5 报告不自动/不持久显示 | 高 | 关作品/新故事时自动生成学习故事；成长册启动加载已存故事，避免重复生成 |
| 4 | B3 对象定位不可达 | 中 | 工具栏加"选择"工具（或长按选中），让"只动这个"可用 |
| 5 | A1 跨拍记忆 | 中 | 把 noticed + 孩子确认沉淀成"已知画面"，回传模型，给连续认知 |
| 6 | A2/A4/A5 | 中·健壮 | figure 加超时；方言时切对应 TTS 音色或提示；全语音留文字降级开关 |
| 7 | A3 编排测试 | 中 | 抽 useTurn/useCreations hook，给 runTurn 关键分支补测 |
| 8 | V1 真人验证 | 最高·别拖 | 真机带一个孩子跑一轮，按观察改 |

> 结论：核心体验对"会说话的单主体创作"已闭环且质量好；**最该补的是 B1（纯画也回应）和 B2（多孩子数据正确）**——前者关乎"是否真的在陪孩子"，后者关乎"数据能不能信"。其次把报告做成自动闭环（B4/B5）。其余按健壮性/一致性补。
