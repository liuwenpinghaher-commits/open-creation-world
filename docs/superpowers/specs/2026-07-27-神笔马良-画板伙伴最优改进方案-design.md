## 1. 背景与问题

### 1.1 真实目标（用户原话收敛）

1. 有一块**交互画板**，孩子边画边和模型基于画聊天。  
2. 聊天内容承担 **AI 时代素质能力引导**（引导而非测评）。  
3. **边画边聊要不打断作画过程**：不靠点按；**关键词唤醒**。  
4. 只画不说时系统应「睡着」不费算力；例：  
   > 「马良，你看我画的这个我的世界城堡怎么样」→ 此时才开始讨论。  
5. **有历史记忆**：窗内多轮无需再喊唤醒词；可自然休眠，再唤醒可续。  
6. **要能打断**：马良说话时孩子插话应停播并听孩子；**禁止**门响、电视、咳嗽、乱碰桌等任意声音误打断。  
7. 家庭自用，**不商业化**时可放宽授权，但架构仍保持可维护、可本地、隐私可控。

### 1.2 历史弯路（必须继续避开）

| 弯路 | 后果 |
|------|------|
| AI 在画布上 `addShapes` / 坐标作画 | 风格违和；AI 与孩子笔触两套世界；「不是我的画」 |
| 分镜/关键帧当主菜 | LLM 弱空间推理；延迟爆炸；孩子变观众 |
| 每拍串行 STT→大模型→TTS（十余秒） | 儿童注意力窗口崩掉 |
| 全双工永远听懂一切 | 自言自语误触发；费钱；隐私差；打断「安静画画」 |
| Hermes / OpenClaw 当交互底座 | 全能 Agent 壳，工具面过大；Canvas≠儿童涂鸦板；教育学约束缺失 |
| 一上来 Mem0/图记忆平台 | 杀鸡用牛刀；作品内连贯靠 transcript 更稳 |

### 1.3 本方案与旧设计的关系

| 保留并强化 | 降级为可选糖 | 明确废弃（主路径） |
|------------|--------------|-------------------|
| tldraw 画布只含孩子笔触 | 偶发 `fulfill` 木偶动画 | AI 几何作画 / 分镜坐标主链 |
| 本地 `guidance/engine` + PEER/CROWD | AnimatedDrawings | 能力打分测评 |
| `PartnerResponse` 契约 + sanitize | 流式全双工 Realtime | 商业社区/排行 |
| family 档案 + work 会话（Dexie） | 跨作品自动画像 notes | Hermes/OpenClaw 产品宿主 |
| 多模态看图 + 伙伴 prompt | — | 按钮式「按住说话」作为唯一入口（可留作兜底） |

## 2. 产品原则（不可再分）

| # | 原则 | 工程含义 |
|---|------|----------|
| P1 | **手永远在画上** | 孩子主路径零按钮；触控留给画笔 |
| P2 | **画画 ≠ 对话** | 无唤醒则不上云 ASR、不截图、不调 LLM |
| P3 | **唤醒 = 邀请对话** | 「马良」同句可带问题；窗内免唤醒 |
| P4 | **孩子产出是发动机** | AI 输出以问题与支架为主，禁止替命名/替写故事 |
| P5 | **引导而非裁决** | 四维能力轮换；不做分数、不做关卡 |
| P6 | **人做主 / AI 会错** | 猜错可纠正；孩子对画的定义有最终权 |
| P7 | **分层反馈** | 落笔即时；语音尽快；理解可慢但不锁画布 |
| P8 | **本地优先隐私** | 休眠仅端侧 KWS；业务数据默认 Dexie |
| P9 | **可打断，难误打断** | SPEAKING 支持孩子插话停播；打断必须过**多层门闩**，禁止能量门限单判 |

## 3. 目标用户与成功标准

### 3.1 用户

- **主**：6–10 岁，可不太识字 → 语音优先、图标轻反馈。  
- **次**：家长 → 建档案、偏好、回看作品；不要求盯着测评。

### 3.2 成功信号（定性，家庭自用）

1. 孩子能独立完成：画 → 喊马良说话 → 听到回应 → 继续画/说。  
2. 只画不喊时，系统保持安静（可观察：无 thinking、无云端调用）。  
3. 一次唤醒后可连续多轮，**无需每句「马良」**。  
4. 静默一段时间后自然休眠；再喊可续**同一幅画**的上下文。  
5. 引导下愿意多描述、多想一步；会纠正 AI 的猜错（agency）。  
6. 愿意再打开继续画（回访）。  
7. 马良说话时能插话打断；噪声/回声不轻易打断（§7.7 / J9–J10）。

### 3.3 明确非目标（Non-Goals）

- 不做精美 AI 视频/替孩子成画。  
- 不做能力评分、家长能力排名。  
- 不做因果物理模拟世界（旧「创造世界」方向）。  
- 不做 Hermes/OpenClaw 整包产品化。  
- 不做「任意环境声一响就停播」的伪打断（能量 VAD 单门闩）。  
- 不做无门闩的全双工电话感（始终双向裸听）。  
- 不做纯 LLM 自选素质维度、不做 LLM Wiki 当策略主脑。  
- P0–P2 不接 Mem0/图记忆中间件；不引入 Pipecat/LiveKit 作默认语音底座。

## 4. 核心体验循环

```text
[安静画画]
  端侧只跑唤醒词「马良」——零云端

[邀请]
  孩子：「马良，你看我画的城堡怎么样？」
  → 唤醒 + 同句 ASR + 截画 + 档案 + 会话历史
  → 伙伴：看见 → 肯定/推进一格 → 一句问

[连续聊 · 免唤醒]
  孩子边画边答：「门太小了我想加大」
  → 仅 ASR +（画变则截图）+ 追加 dialog
  → 再问一句 / 偶发兑现动画

[自然睡]
  静默 ≥ T_follow_up → 语音 SLEEP
  Work 已落盘；dialog 保留

[再醒]
  「马良，屋顶呢？」→ 同一 workId 续聊
```

## 5. 素质引导模型（AI 时代 × 儿童可玩）

### 5.1 发展核心（每活跃拍可轮换）

| 维度 | 目标 | 主手段（CROWD） |
|------|------|-----------------|
| `observe_express` | 观察、描述、命名 | open / wh |
| `narrative_logic` | 因果与叙事连贯 | recall / completion / wh |
| `imagination` | 发散与如果… | open / distancing |
| `problem_solving` | 温和障碍 + 自己想办法 | wh / completion |

- **策略主权在本地**（见 §5.3）：`guidance/engine.ts` 产出本拍 `move`（维度、CROWD、支架高低）。  
- **LLM 只润色**：把 `move` 说成温暖口语；禁止自行改策略轴、禁止自创维度。  
- **结构 PEER**：肯定（E）→ 扩展一格（E）→ 提问/邀请（P）；卡住则高支架（二选一/半句填空）。  
- **最优形态不是「死板转盘」**，而是 **信号增强的本地策略**（§5.3.3）；也不是「整段交给大模型」或「LLM Wiki 当策略主脑」。

### 5.2 AI 元素养（低频嵌入，不单独上课）

| 素养 | 可玩行为 |
|------|----------|
| 人做主 | 画是你的；你说了算 |
| AI 会错 | 大胆猜 + 请纠正 |
| 可反驳协作 | 可有不同看法，不嘲讽 |
| 多模态表达 | 鼓励指着画说、画一点再讲 |

不把 UNESCO 四维做成概念课；只落实为对话行为。

### 5.3 策略层 × 人设层 × 知识层（冻结裁决）

> 回答三个常见疑问：  
> 1）本地策略是不是劣质方案？  
> 2）这是不是 Agent 能力设定？  
> 3）要不要 LLM Wiki 动态加载策略？

#### 5.3.1 三层拆分（不要混成一层 prompt）

| 层 | 解决的问题 | 变不变 | 本仓落点 | 类比 |
|----|------------|--------|----------|------|
| **人设层** | 你是谁、语气、禁区、伙伴名 | 慢变（档案/家长偏好） | `ChildProfile` / `GuidancePrefs` → `ChildContext`；partner system 人设段 | Agent profile / 能力与性格设定 |
| **策略层** | **这一拍**往哪推、题型、难不难 | **每拍** | `guidance/engine.ts` → `GuidanceMove` | 对话管理 DM / Dialog Policy |
| **生成层** | 看着画把约束说成口语 | 每拍 | `server/partner.ts` + 多模态 LLM | NLG |
| **知识层（可选）** | 资料太多时按需取一段说明 | 按需 | 配置化 PLAYBOOK / 条件片段；**默认不上 Wiki** | 说明书抽屉，不是考官 |

```text
人设（慢） + 策略 move（每拍，本地主权）
        → 可选：按 move/档案 拼接 prompt 片段
        → LLM 看画 + 历史 + 约束 → 一句口语
```

| 若只做… | 后果 |
|----------|------|
| 只做人设、不做每拍策略 | 模型自由发挥 → 偏科、说教、越界、不可测 |
| 只有死板轮换、无人设 | 问法对但没温度 |
| 用 Wiki/RAG 替代策略状态机 | 资料≠「下一拍练哪维」；决策权悬空或又丢回模型 |

**冻结：** 人设 ≠ 策略；策略 ≠ 知识检索。可协作，**策略主权不可交给 LLM 或 Wiki。**

#### 5.3.2 本地策略是不是「不好」？

| 误解 | 澄清 |
|------|------|
| 本地 = 土、不 AI | 本地 = **policy 引擎**；语音助手/对话式共读工业里标准结构是 DM 本地 + NLG 生成 |
| 聪明就该全模型定考纲 | 模型强在理解画面与措辞；弱在长期遵守教育学节奏与可测轮换 |
| 规则就不能动态 | 规则可读档案、画/话线索、投入度、家长权重——仍本地，但可自适应 |

**真正要避免的**是实现成「无视现场的纯转盘」。  
**要保留的**是：维度可轮换、卡住必降支架、禁止越界、单测可红可绿。

#### 5.3.3 策略方案对比与最优默认

| 方案 | 做法 | 裁决 |
|------|------|------|
| **A. 纯本地轮换** | history + stuck → move | ✅ 底线可上线；易偏机械 |
| **B. 纯 LLM 策略** | 模型自选维度/CROWD/难度 | ❌ 禁止作主路径 |
| **C. LLM 提议 → 本地否决** | 模型出 move，engine 校验 | ⚠️ 贵、易糊；非默认 |
| **D. 本地候选 → 有限点菜** | engine 给 2～3 个合法 move，再选 1 个 | ✅ 可选增强（贴切↑） |
| **E. 信号增强本地** | 仍本地定 move，输入加现场信号 | ✅✅ **最优默认** |
| **F. 老虎机/RL 调权重** | 按多说多画调维 | 后期；数据少不上 |
| **G. LLM Wiki / RAG 当策略** | 检索篇章决定引导 | ❌ **禁止作策略主脑**（见 §5.3.6） |

**最优默认（冻结）= E：信号增强的本地策略；LLM 只润色。**  
可选叠加 **D**（合法候选内点菜）——分期见 **§13**。  
**永不**采用 B 或 G 作为策略主权。

#### 5.3.4 信号增强本地（E）——engine 输入与优先级

```text
move = f(
  dimHistory,          // 均衡，防偏科
  engagement,          // stuck | normal | flowing（已有）
  parentWeights,       // 家长维度权重（已有）
  contentHints,        // ★ 画/话轻量线索（规则，非再调模型）
  turnInSession,       // ★ 开场偏观察，中段可叙事/想象
  lastChildAct         // ★ 刚猛画 → 少打断、偏观察；刚长说 → 可推因果
)
```

**信号冲突时优先级（高 → 低，冻结）：**

| 优先级 | 规则 | 说明 |
|--------|------|------|
| 1 | `engagement=stuck` → 高支架 + 具体维 | 安全与体验底线 |
| 2 | 连续 ≥2 拍同维 → **强制换维** | 防偏科；高于兴趣线索 |
| 3 | `parentWeights` 加权轮换 | 家长意图 |
| 4 | `contentHints` / `lastChildAct` / `turnInSession` | 贴现场；不得压过 1–2 |
| 5 | 默认均衡 `nextDimension` | 无线索时的底 |

**contentHints 规则示例：**

| 线索 | 策略偏向 |
|------|----------|
| 画变很多、话少 | `observe_express`；pace 偏留白 |
| 话含「然后/因为/后来」 | 可跟 `narrative_logic` |
| 话含「如果/变成/魔法」 | 可跟 `imagination` |
| 话含「怎么办/过不去」 | 可跟 `problem_solving` |

**D（可选）形态：**

```text
engine.proposeMoves(k=2|3) → 合法 move 列表
→ 本地打分选最优  或  模型仅输出 chosenIndex∈[0,k)
→ 禁止模型自创 dimension / crowd / support
```

#### 5.3.5 人设 vs Agent 能力设定 vs 策略

| 概念 | 是什么 | 马良怎么做 |
|------|--------|------------|
| Agent 人设/能力设定 | 身份、语气、工具列表、总禁区 | `ChildContext` + system 禁区（不替画/不替写故事/不坐标） |
| 对话策略 / DM | **本步交互目标** | `GuidanceMove` 每拍 |
| Skills / 工具 | 可调用外部能力 | 默认无；fulfill 为本地动作词表，非通用 Agent 工具 |

结论：**本地策略 ≈ 轻量 Dialog Manager，不是「写进人设 prompt 就等于做了引导」。**  
仅有人设、无每拍 move = 未完成素质引导架构。

#### 5.3.6 知识层与 LLM Wiki：默认不上

| 手段 | 适合 | 不适合 |
|------|------|--------|
| **配置化 PLAYBOOK**（推荐） | 维度→目标/问法/示例；卡住支架话术；TS/JSON 常量 | — |
| **按档案条件拼片段** | age、兴趣、SEL 开关 → 多拼一段 system | 替代 move 状态机 |
| **LLM Wiki / RAG 动态加载** | 规范/话题库膨胀、多产品共用长文档 | **每拍选维度**；当策略主脑 |

**「动态」的正确轻量做法：**

```text
1. engine 算出 move
2. 按 move.dimension + support + childContext 取 PLAYBOOK 片段 key
3. 拼进 partner system / user 约束
4. LLM 生成口语
```

这是 **条件化 prompt 装配**，不是 Wiki 中台。

| Wiki 作策略主脑的问题 | 说明 |
|----------------------|------|
| 加载哪篇仍要决策 | 若再丢给模型 → 不可测；若本地定 key → Wiki 退化成 PLAYBOOK |
| 延迟与复杂度 | 检索加链路，儿童场景不值 |
| 概念错位 | Wiki=资料；策略=状态机 |

**冻结：** P0–P2 **不引入** LLM Wiki / 记忆中台式知识图谱作引导策略。  
内容真膨胀后再评估「片段库检索」，且 **检索 query/key 仍由 engine 或配置表决定**。

#### 5.3.7 模块与实现要点

| 模块 | 职责 |
|------|------|
| `guidance/engine.ts` | 策略主权：输入信号 → `GuidanceMove` 或 `proposeMoves`；纯函数、单测覆盖轮换/卡住/强制换维/线索 |
| `server/partner.ts`（PLAYBOOK） | 人设 + 按 move 注入的玩法说明；模型禁改轴 |
| `sanitize` | 输出合法性；可选校验 dimension 与请求 move 一致 |
| 编排层 | 组装 contentHints（画是否变化、末句关键词等）喂 engine |

**反模式（策略章守门）：**

- 去掉 engine，只靠「你是启发式伙伴」一段 prompt  
- 模型 JSON 自带任意 dimension 且本地不校验  
- 用 Mem0/Wiki/RAG 结果直接当本拍考纲  
- 把 Hermes/通用 Agent skills 当素质维度轮换  

#### 5.3.8 策略层与总分期的关系

策略交付条目已并入 **§13**（唯一分期真源）。此处仅索引：

- 已有：轮换 + engagement + 权重 + PLAYBOOK  
- §13 阶段 3/4：强制换维、sanitize 锁轴、contentHints（E）  
- §13 阶段 5+：可选 D / 片段库（仍禁 Wiki 夺权）

#### 5.3.9 一句话（策略章）

> **人设定「你是谁」；本地策略定「这一拍往哪推」；PLAYBOOK/片段定「怎么说的说明书」；LLM 定「嘴里那句人话」。**  
> 最优 = **信号增强的本地策略主权 + 配置化话术包 + 模型润色**；不用纯模型策略，不用 LLM Wiki 当考官。

## 7. 语音：唤醒 · 连续会话 · 休眠

### 7.1 状态机（VoiceSession）

| 状态 | 行为 | 云端 ASR | 截图/LLM | 孩子感知 |
|------|------|----------|----------|----------|
| **SLEEP** | 仅端侧 KWS | 关 | 关 | 安静可画 |
| **ARMING** | 仅唤醒词、尚无有效句 | 短窗 | 否 | 可选极轻「嗯？」 |
| **LISTENING** | 收句 + VAD | 开 | 否（等 final） | 可边画边说 |
| **THINKING** | 组请求、等伙伴 | 关或降* | 是 | 角标思考，不锁画 |
| **SPEAKING** | TTS 播放；麦开但强门闩 | 打断侦测通道 | 否 | 听马良 |
| **BARGE_CANDIDATE** | Soft-Pause；待硬确认 | 开（偏 G2） | 否 | 马良顿住 |
| **FOLLOW_UP** | 答完后继续听 | 开 | final 时 | **免唤醒**多轮 |

\*THINKING 期默认不把新语音当新一轮（见 §7.8）；可缓存一句「插话」待返回后处理。

```text
SLEEP
  --KWS「马良」--> 若同句有内容: strip → LISTENING→… 
                  若仅唤醒词: ARMING → 等首句 / 超时→SLEEP

FOLLOW_UP | LISTENING
  --final 有效句--> THINKING → SPEAKING → FOLLOW_UP
  --静默 ≥ T_follow_up--> SLEEP（flush saveWork）
  --休眠词--> SLEEP

SPEAKING
  --G3 唤醒词--> LISTENING（硬断，跳过候选）
  --疑似人声(T_suspect)--> BARGE_CANDIDATE + Soft-Pause
BARGE_CANDIDATE
  --硬确认 (G1∧G2) 或 G3--> LISTENING
  --超时/回声/噪声--> SPEAKING 续播
```

> **硬规则**：能量变大 **绝不**直接 hard barge；硬确认公式见 §7.7.4。

### 7.2 超时参数（初值，真孩子可调）

| 参数 | 初值 | 含义 |
|------|------|------|
| `T_follow_up` | **15s** | 答完后免唤醒窗口（儿童可调到 12–20s） |
| `T_first_utt` | **10s** | 只喊名后等第一句 |
| `T_max_active` | **5min** | 无有效轮次则强制睡 |
| `min_utt_chars` | **2** | 过滤纯语气词单独调模型（可记 log） |

### 7.3 唤醒词

| 项 | 规格 |
|----|------|
| 主词 | 「马良」或「嘿马良」（两音节更稳可选嘿马良） |
| 同句 | 支持「马良你看…」：KWS 命中后同窗音频整段 ASR，再 strip |
| 休眠词 | 「马良再见」「不聊了」「你先忙」→ 立即 SLEEP |
| 引擎 | **端侧**优先：Picovoice Porcupine（中文/自定义/Web WASM） |
| 禁止 | 以「全程云端转写再搜关键词」为主路径 |

### 7.4 语音链路选型

| 能力 | 推荐 | 备注 |
|------|------|------|
| STT | 百炼/DashScope **流式 ASR** | 与现有 qwen 生态一致；partial→字幕，final→业务 |
| TTS | **流式 TTS**（qwen-tts 或实时合成） | 替代整段下载再播 |
| 批处理 STT/TTS | 保留为降级 | 流式失败时 fallback |
| 打字输入 | 家长/调试兜底 | 非儿童主路径 |
| 浏览器 Web Speech | 不作为主底座 | 中文与稳定性不足 |

### 7.5 平台约束（诚实）

- 浏览器需**家长首次手势**授予麦克风；之后对孩子无点击。  
- 这是平台限制，产品文案：「家长点一次开始陪伴」。

### 7.6 与 OpenClaw Voice Wake 的关系

- **只借状态机思想**（全局触发词、路由、休眠）。  
- **不**引入 OpenClaw Gateway 作为运行时。  
- 实现落在本仓 `src/voice/session.ts`（建议路径）+ 薄后端代理。

### 7.7 打断（Barge-in）：要能打断，且不能误打断

#### 7.7.1 产品定义

| 场景 | 期望 |
|------|------|
| 马良正在说，孩子清晰插话「不对，是龙！」 | **停播**，进入 LISTENING，吃完这句再答 |
| 马良正在说，孩子再喊「马良」 | **停播**（KWS 硬打断，最高优先级） |
| 关门、碗筷、电视、桌面碰撞、短促咳嗽、笑声余音 | **不停播** |
| 扬声器放出的马良自己的声音被麦收到 | **不停播**（回声） |
| 孩子边听边轻轻哼两声 / 吸鼻子 | **不停播** |

原则一句话：**打断的是「人在说话」，不是「声音变大了」。**

#### 7.7.2 禁止的错误实现（反模式）

| 反模式 | 为何会烂 |
|--------|----------|
| 仅 RMS/音量阈值 | 任意噪声过线即断 |
| 仅 WebRTC VAD 单帧 speech=true | 脉冲噪声、音乐也常误报 |
| TTS 播放时完全静音麦克风 | 无法插话（过度安全） |
| TTS 播放时裸开 ASR 无门闩 | 回声把马良的话当孩子话，自问自答或狂打断 |
| 一有 partial 就硬断且 partial 是乱码 | 噪声被识别成碎字也断 |

#### 7.7.3 两阶段打断（推荐默认）

不要「疑似人声 → 立刻杀掉整句」。用 **候选 → 确认 / 撤销**：

```text
SPEAKING
  │
  ├─ E0–E2 过 + 类人声持续 ≥ T_suspect_ms
  │     → BARGE_CANDIDATE + Soft-Pause（可恢复）
  │
  ├─ 在 T_confirm 内硬确认成功
  │     → Hard Barge-in → LISTENING；后续 final 为孩子新话
  │
  └─ 未确认 / 回声 / 噪声
        → 续播（resume 优先；失败则重播本句）
```

| 阶段 | 对播放 | 算打断？ |
|------|--------|----------|
| Soft-Pause | 暂时停 | **否** |
| Hard Barge-in | 永久停本句 | **是** |

#### 7.7.4 硬确认公式（v2.0 冻结 · 抗误判关键）

**前置（必须全部满足）：** E0 回声抑制、E1 起播保护窗、E2 冷却（见下表）。

**硬打断 Hard Barge-in 当且仅当：**

```text
Hard = (G1 ∧ G2)  ∨  G3
```

| 符号 | 条件（初值） | 作用 |
|------|----------------|------|
| **G1** | speech 帧累计 ≥ **`T_speech_min_ms`（400）**，概率均值 ≥ **`speech_prob_min`（0.7）** | 持续人声，非砰咔 |
| **G2** | 流式 ASR partial 去噪后 ≥ **`partial_min_chars`（2）** 汉字，且非 ignore 语气词 | 有语义，非碎音 |
| **G3** | KWS 命中「马良/嘿马良」 | 最强意图；**可跳过 soft 直达硬断** |
| **G4** | 可选声纹（后期） | 滤电视/远处大人 |

| 问 | 答 |
|----|-----|
| 为何不用「仅 G1」硬断？ | 电视/旁人说话可持续像「语音」→ 误硬断（审查 P0） |
| 为何 Soft 仍可靠疑似人声？ | 只暂停可恢复；误触发代价低 |
| 「灵敏档」可调什么？ | 略降 `T_speech_min` / `partial_min_chars`；**不可**改回能量单判或仅 G1 hard |

**前置 E0–E2：**

| 前置 | 要求 |
|------|------|
| **E0** | AEC + 播放中打断通道降敏；自声不计入 G1 |
| **E1** | TTS 起播后 **`T_play_guard_ms`（250）** 内禁止进候选 |
| **E2** | 撤销后 **`T_barge_cooldown_ms`（500）** 内不再进候选 |
| **Echo 否决** | partial 与 `tts_text` 相似度 ≥ `echo_text_similarity` → **禁止**硬断并撤销候选 |

#### 7.7.5 状态机增量：`BargeCandidate`

```ts
type VoicePhase =
  | 'sleep' | 'arming' | 'listening' | 'thinking'
  | 'speaking' | 'barge_candidate' | 'follow_up'
```

| 转移 | 条件 |
|------|------|
| SPEAKING → BARGE_CANDIDATE | E0–E2 + 类人声 ≥ **`T_suspect_ms`（150）** |
| BARGE_CANDIDATE → LISTENING | **(G1∧G2) 或 G3** |
| BARGE_CANDIDATE → SPEAKING | 超时未确认 / 概率塌缩 / Echo 否决 |
| SPEAKING → LISTENING | **仅 G3** 直达 |

#### 7.7.6 回声（最高优先级工程点）

马良的 TTS 从扬声器进麦克风是误打断与「自言自语」的第一元凶。

| 手段 | 说明 |
|------|------|
| **AEC** | 浏览器/系统有限；桌面可 WebRTC AEC 约束 |
| **参考衰减** | 已知正在播放：提高打断阈值，或从输入中估计回声 |
| **半双工增强** | SPEAKING 时 ASR 只做「打断侦测通道」，灵敏度低于 LISTENING |
| **TTS 文本忽略** | 若 partial 与当前播报文案高度重合 → 视为回声，**禁止**硬断 |

「partial ≈ 正在播的字」→ **强制撤销候选**（关键启发式，家庭场景很有效）。

#### 7.7.7 LISTENING / FOLLOW_UP 与 SPEAKING 的阈值差

| 状态 | 目标 | 策略松紧 |
|------|------|----------|
| LISTENING / FOLLOW_UP | 听清孩子一整句 | 正常 VAD 切句；仍滤纯噪声 |
| SPEAKING | 几乎只响应「真插话」 | **更严**：两阶段 + G1/G2/G3；默认不因能量断 |

#### 7.7.8 打断后的对话语义

1. Hard barge-in → 停 TTS，**不把未说完的伙伴句写入 dialog**（或写入并标记 `truncated: true`，默认：**不写入**，避免半句话污染上下文）。  
2. 孩子 final 正常入 dialog → THINKING → 新回答。  
3. 若 hard barge-in 后 `T_first_utt` 内无有效 final → 可轻声「你说，我在听」或恢复 FOLLOW_UP 计时，**不要**自动重播被打断的整句（避免烦）。可选：家长设置「被打断后是否重说」。

#### 7.7.9 参数表（打断专用，可配置 · 与 §17 同步）

| 参数 | 初值 | 说明 |
|------|------|------|
| `barge_enabled` | `true` | 总开关 |
| `T_suspect_ms` | `150` | 进入 soft 候选的最短类人声 |
| `T_speech_min_ms` | `400` | **G1** 硬确认用持续语音 |
| `speech_prob_min` | `0.7` | G1 概率 |
| `T_confirm_ms` | `800` | soft 待确认窗（等 G2 等） |
| `T_play_guard_ms` | `250` | 起播保护 |
| `T_barge_cooldown_ms` | `500` | 撤销后冷却 |
| `partial_min_chars` | `2` | **G2** |
| `ignore_tokens` | `嗯,啊,呃,哦,额,唔` | 不单独构成 G2 |
| `echo_text_similarity` | `0.75` | Echo 否决 |
| `wake_hard_barge` | `true` | G3 直接硬断 |
| `soft_pause` | `true` | 先暂停再确认 |
| `hard_formula` | `(G1&&G2)\|\|G3` | **不可配置为仅能量** |

#### 7.7.10 实现模块

| 模块 | 路径建议 | 职责 |
|------|----------|------|
| 打断门闩 | `src/voice/bargeGate.ts` | 纯逻辑：帧序列 → candidate / confirm / reject（**可单测**） |
| 回声启发 | `src/voice/echoGuard.ts` | 播报文 vs partial 相似；播放中标志 |
| FSM | `src/voice/session.ts` | 含 `barge_candidate` |
| 播放器 | `useVoice` 扩展 | pause / resume / stop；上报 `tts_text` 供 echoGuard |

**单测必覆盖（无麦也可）：**

1. 短脉冲高能量 → 不 hard  
2. 仅 G1 满 400ms、无 G2 → **不 hard**（v2.0）  
3. G1 + partial「不对」→ hard  
4. partial「嗯」→ 不 hard  
5. partial ≈ tts_text → Echo 否决  
6. 起播 200ms 内 → 不进候选  
7. KWS → 直接 hard  
8. soft 后超时 → resume，无半截 dialog  

#### 7.7.11 验收（打断专条）

| ID | 场景 | 通过 |
|----|------|------|
| B1 | 播放中孩子说完整短句 | hard 停播并接话 |
| B2 | 拍手/关门/敲桌 | 不 hard；或 soft 后**续播** |
| B3 | 电视人声（非近讲） | **不 hard**（缺 G2/G3） |
| B4 | 马良自声回灌 | 不 hard（Echo） |
| B5 | 再喊「马良」 | 立即 hard |
| B6 | soft 误触发 | 续播完整；dialog 无半截伙伴句 |
| B7 | 仅持续噪声被 VAD 当成语音、无 partial | **不 hard** |

家庭手测：噪声组误硬断 **≤1/5**，插话组成功硬断 **≥4/5**。

#### 7.7.12 开源复用清单（VAD / AEC / 可选 Pipecat）

> **边界先说清**：业界有现成 **VAD 零件** 和 **实时语音 Agent 框架**，**没有**「儿童画板专用、插上即完美抗误打断」的单一 SDK。  
> **复用感知，自研策略**：帧级「像不像人声」用开源；soft/hard、G1–G3、echo 文案否决、与 `VoiceSession`/作品会话衔接 **仍按 §7.7.3–7.7.9 本仓实现**。

| **VAD 模型本体** | Silero VAD | [snakers4/silero-vad](https://github.com/snakers4/silero-vad) | 服务端或训练/对照；浏览器优先走 ricky0123 | MIT |
| **基础 AEC / 降噪** | 浏览器约束 | `getUserMedia({ audio: { echoCancellation: true, noiseSuppression: true, autoGainControl: true } })` | **E0 回声前置**；SPEAKING 期必开 | 各浏览器效果不一，Firefox 较弱 |
| **唤醒硬断 G3** | Porcupine 等 KWS | [Picovoice Porcupine](https://github.com/Picovoice/porcupine)（与 §7.3 一致） | 播放中再喊「马良」→ 直接 hard barge | 中文自定义词；家庭自用不纠结商用条款时可放宽 |
| **流式 ASR partial（G2）** | 现有/规划的流式 STT | 百炼等（与 §7.4 一致） | partial ≥2 字且非 ignore 表 → 硬确认 | 非 VAD 库，但是 G2 现成能力 |

**P0 默认组合（不换产品底座）：**

```text
getUserMedia(AEC+) + ricky0123/vad（G1）
  + 流式 ASR partial（G2）
  + Porcupine「马良」（G3）
  + 本仓 bargeGate / echoGuard / VoiceSession（策略）
```

##### E. 实现落点与依赖原则

| 原则 | 说明 |
|------|------|
| 最小依赖 | P0 优先：浏览器 AEC + `ricky0123/vad` + 现有/规划 STT + Porcupine + 本仓门闩 |

##### F. 复用对照（避免重复造轮子）

| §7.7 概念 | 复用谁 | 自研谁 |
|-----------|--------|--------|
| E0 回声抑制 | 浏览器 AEC + echoGuard 文案启发式 | 启发式本身 |
| E1/E2 保护窗/冷却 | — | bargeGate |
| G1 持续语音 | Silero / ricky0123/vad | 累计时长与阈值 |
| G2 有效 partial | 流式 ASR | 字数与 ignore 表 |
| G3 唤醒硬断 | Porcupine | FSM 直达 LISTENING |
| Soft/Hard 两阶段 | — | session + 播放器 pause/resume/stop |
| Hard 公式 | — | `(G1∧G2)∨G3` 写死在 bargeGate |

### 7.8 并发、异常与边界（审查补全）

| 场景 | 处置（冻结） |
|------|----------------|
| **THINKING 时孩子又说话** | 不并行开第二轮 partner；可选缓存 latest final，本轮返回后 **只处理最新一句**（或丢弃缓存，避免乱序） |
| **THINKING 时 KWS「马良」** | 不取消 in-flight 请求；返回后进入 FOLLOW_UP；重复唤醒忽略 |
| **SPEAKING 时 partner 又推新句** | 禁止叠播；队列至多 1 条，barge 后清空未播队列 |
| **TTS 失败** | 文字兜底 + 进 FOLLOW_UP；不卡死 SPEAKING |
| **STT/partner 超时或 5xx** | fail-loud 短提示；回 FOLLOW_UP 或 SLEEP；**不**假成功 |
| **页隐藏 / 切应用** | pause TTS；flush saveWork；回前台保持 session，语音可回 SLEEP 需再唤醒 |
| **切娃 / 新作品** | 先 flush 旧 work；Voice → SLEEP；清空 A 层内存 dialog 指针到新 work |
| **隐私模式** | 不传画布图；仅语音+sceneNote/dialog；引导仍可用 |
| **无麦克风权限** | 家长引导授权；提供调试打字兜底，儿童主路径仍目标语音 |

## 8. 记忆：孩子档案 × 会话

### 8.1 分层（冻结）

## 9. 伙伴契约与引导（沿用并收紧）

> 策略与人设的分层以 **§5.3** 为准；本章只定 **生成契约** 与硬约束。

### 9.1 PartnerResponse（保持无坐标）

```ts
type PartnerResponse = {
  noticed: string
  dimension: GuidanceDimension
  crowd: CrowdType
  peer?: { evaluate?: string; expand?: string }
  provoke: string                 // 必填：对孩子说的主句（宜短、口语）
  fulfill?: { behavior: Behavior; trigger: string } | null
  childSignal?: string
}
```

### 9.2 硬约束（prompt + sanitize）

1. 不输出像素/归一化坐标。  
2. 不替孩子最终命名（可用「我觉得像…是不是」邀请纠正）。  
3. 不替孩子写完整故事情节。  
4. `fulfill` 仅当孩子**明确**要求动作。  
5. 一拍主输出以**一句**可听文本为主（evaluate/expand 可并入或极短）。  
6. 遵守本拍 `move` 的维度与 CROWD，不得自行改轴；若返回 dimension 与请求不一致 → sanitize 纠正或重试。  
7. 不得因「检索到的 wiki/记忆片段」覆盖本拍 move（知识层不得夺策略主权，§5.3.6）。

### 9.3 偶发兑现（糖，非发动机）

- 词表：`fly | grow | spin | hop | walk | bounce | wobble`  
- 作用对象：**当前画布上孩子真实笔触**整体 rig  
- 本地几何 + 现有 tween；禁止 LLM 给路径点  

### 9.4 播报拼装（TTS 说什么 · 审查补全）

| 规则 | 说明 |
|------|------|
| **主播报句** | 默认只 TTS **`provoke`**（一句问/邀请） |
| **可选前缀** | 若 `peer.evaluate` 非空且短（≤20 字），可拼在 provoke 前，中间短停顿；总时长宜 &lt; 12s |
| **不播** | `noticed`、`childSignal`、原始 JSON、长 expand（expand 可并入 provoke 由模型控制） |
| **`tts_text`** | 实际拼接后的字符串，供 Echo 否决与「再听一次」 |
| **硬断后** | 未播完的 `tts_text` **不**写入 dialog |

sanitize 后：`spoken = join(evaluate?, provoke)` → speak(spoken) → 状态 SPEAKING。

### 14.3 反模式守门（出现即失败）

- AI 主路径写故事/替命名定论

- 儿童必须点按钮才能说话（家长授权除外）  
- LLM 输出坐标作画  
- 把 Hermes/OpenClaw 嵌成主 UI  
- **能量 VAD 单门闩硬打断** 或 **仅 G1 硬打断**

- **取消本地策略、纯 LLM 自选维度**  
- **LLM Wiki/RAG 充当每拍考纲**  
- 叠播多路 TTS / THINKING 并行多轮 partner

## 15. 风险与对策

| 风险 | 等级 | 对策 |
|------|------|------|
| 童声唤醒不准 | 中 | 可训「嘿马良」；灵敏度可调；ARMING 误唤醒无 final 不调 LLM |
| 画画自言自语误触发 | 中 | 必须 KWS；无 final 不工作 |
| **误打断（噪声/回声）** | **高** | §7.7 两阶段 + G1/G2/G3 + echo 否决；禁止能量单判；B 组手测门禁 |
| **想打断却断不了** | 中 | G3 唤醒词硬断兜底；G2 partial 阈值可调「灵敏档」 |
| ASR 延迟 | 中 | 流式字幕；final 才伙伴；soft-pause 掩盖确认延迟 |
| 模型越界 | 中 | prompt + sanitize + 单测样本 |
| 浏览器麦权限 | 低 | 家长一次授权文案 |
| App.tsx 继续膨胀 | 中 | FSM/编排强制分文件；PR 卡行数 |
| 范围蔓延回动画大片 | 高 | 本文 Non-Goals + 阶段门禁 |

## 19. 总结

本方案（**v2.0**）把「神笔马良」冻结为：

1. **画板自建底座**（tldraw + partner + guidance + family/work）  
2. **端侧唤醒 + 活跃窗连续语音**（非 Agent 壳）  
3. **可打断难误打断**：Soft + **Hard=(G1∧G2)∨G3** + Echo 否决  
4. **档案记人、会话记画**；P0–P2 不上 Mem0  
5. **引导四层**：人设 / 信号增强本地策略 / PLAYBOOK / LLM 润色  
6. **分期真源 §13**；MVP = 阶段 1+2+3
