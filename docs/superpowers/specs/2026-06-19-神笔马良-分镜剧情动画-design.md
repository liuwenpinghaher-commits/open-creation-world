# 神笔马良 · 分镜剧情动画 — 设计文档

> 日期：2026-06-19 ｜ 分支：`feat/magic-brush` ｜ 状态：待评审
> 一句话：把现有"一串互不相关的属性补间"升级为**由孩子语音逐拍共创的分镜时间线**，每个分镜内多元素并行演出、跨分镜表达角色互动，配旁白与 TTS 同步，可整段回放。

---

## 1. 背景与目标

**现状问题**：动画模型是扁平的 `AnimationStep[]`，`runAnimation` 把每个 step 按 `at` 排序后**串行**跑 `editor.animateShape`（只能补间 x/y/旋转/透明度）。结果只是"逐个位移"，谈不上剧情，也无法多元素同拍协同。

**目标**：让画面"演"出有剧情的小故事，且剧情**由孩子每一拍语音共创、可改写**——不是一次性生成的电影，而是开放循环里逐步长出来的分镜时间线。

**选定路线（B）**：自建**轻量 RAF 演出引擎**（约 300 行，**零新依赖**），不引入 GSAP/anime.js，保持 tldraw 为唯一数据源、保持项目极简定位。

**互动如何产生**：由 AI 把互动**写进分镜剧本**（跨分镜编排：镜1 小狗 `moveTo` 骨头 → 镜2 骨头 `disappear` + 小狗 `wobble` 开心）。不做客户端真碰撞/触发引擎。剧本随孩子每拍语音 `append` / `rewrite` 增量生成。

**非目标（明确不做）**：卡通挤压拉伸的真实角色表演（`wobble` 暂顶替"开心抖动"，引擎留扩展位）；物理碰撞/涌现式触发；待机循环动画（idle loop）；Dexie 持久化（属另一计划）。

---

## 2. 数据模型

把 `CocreateResponse.animation: AnimationStep[]` 替换为增量式分镜指令；`SessionState` 增加 `scenes`。坐标一律归一化 `0..1`。

```ts
// src/types/cocreate.ts

/** 一个角色在一个分镜里的演出动作（声明式，由 AI 产出） */
export type ActorAction = {
  shapeId: string                       // 必须引用画布上已存在的简笔画 id
  do: 'enter' | 'disappear' | 'moveTo' | 'scaleTo' | 'rotateTo' | 'wobble'
  x?: number; y?: number                // moveTo / enter 目标位置
  path?: { x: number; y: number }[]     // moveTo 可走弧线/路径（缺省走直线）
  scale?: number                        // scaleTo 目标缩放（相对原始尺寸）
  rotation?: number                     // rotateTo 目标角度（度）
  ease?: 'linear' | 'easeOut' | 'easeInOut' | 'bounce'  // 缺省 easeOut
  durationMs?: number                   // 缺省 600
}

/** 一个分镜：一句旁白 + 镜内全部动作并行演出 + 演完停顿 */
export type Scene = {
  id: string
  narration?: string                    // 这一镜的旁白，与 TTS 同步念、故事区高亮
  actions: ActorAction[]
  holdMs?: number                       // 演完停顿，缺省 400
}

/** CocreateResponse 中的增量分镜指令（与 story 同构：可追加/改写） */
export type SceneDirective = {
  append?: Scene[]
  rewrite?: { from: number; scenes: Scene[] }   // 从第 from 个分镜起整体改写
}

export type CocreateResponse = {
  understanding: string
  guidanceIntent?: { dimension: GuidanceDimension; move: string }
  askChild?: string
  addShapes?: SketchShapeSpec[]
  modifyShapes?: ShapePatch[]
  scenes?: SceneDirective                // ← 取代旧的 animation
  story?: { append?: string; rewrite?: { from: number; text: string } }
  speak: string
}

export type SessionState = {
  shapes: SketchShapeSpec[]
  scenes: Scene[]                        // ← 新增：分镜时间线（累积）
  story: StoryEntry[]
  dialog: { role: 'child' | 'system'; text: string }[]
}
```

`AnimationStep` 类型删除。

## 3. 演出引擎（替换 `runAnimation.ts`）

新文件 `src/animation/playScenes.ts`，对外两个函数：

```ts
playScenes(editor, scenes, fromIndex, canvas, opts): Promise<void>
```

- 从 `fromIndex` 起逐个分镜播放（增量共创时只播新增分镜；改写时从 `from` 起重播）。
- 每个分镜：
  1. 若有 `narration` → 调 `opts.onNarrate(narration)`（触发 TTS 念白 + 故事区高亮，由 App 注入）。念白与镜内动作**并行**开始。
  2. `Promise.all(scene.actions.map(runAction))` —— **镜内全部动作同时演出**（解决现状"逐个串行"）。
  3. `await sleep(scene.holdMs ?? 400)`。
- `runAction` 分派：
  - `moveTo`（直线）/ `rotateTo` / opacity 类 → 优先用 `editor.animateShape`（tldraw 原生补间）。
  - `moveTo`（带 `path`）/ `scaleTo` / `wobble` / `enter` / `exit` → 用**自建 RAF tween**（`editor.updateShape` 逐帧），因为 `animateShape` 不支持路径/宽高/复合。
  - `enter`：shape 置初始（opacity 0、略小）→ tween 到 opacity 1、目标位姿（弹入）。
  - `disappear`（被吃掉/离场）：tween 淡出到 opacity 0，**只隐藏不删除**——数据保留在 `session.shapes`，使整段回放能重演该角色。真正删除只走孩子的 🗑️ 工具，不在演出层发生。
  - 引用了不存在的 `shapeId` → 跳过该 action（不崩，console.warn）。
- 缓动：内置 `linear / easeOut / easeInOut / bounce` 纯函数。

```ts
replayAll(editor, scenes, canvas, opts): Promise<void>
```

- "▶️ 再演一遍"：把分镜涉及的 shape 先隐藏（opacity 0），再从第 0 镜 `playScenes`，由各镜的 `enter`/`moveTo` 把它们演回来。
- 已知简化：不做逐帧精确的位置重建——回放重演的是"出现顺序 + 各镜动作"，元素从当前位置演起；对家用共创足够，完美还原留作后续。

**极小 RAF tween 助手**（同文件内，约 30 行）：`tween(durationMs, ease, onFrame)`，`requestAnimationFrame` 驱动，`onFrame(t∈0..1)`，结束 resolve。`scaleTo` 通过插值 `props.w/h`，`wobble` 通过短促正弦旋转回中，`path` 通过按弧长插值点列。

## 4. 语音共创闭环（增量编排）

每一拍（`App.runTurn`）：
1. 孩子说话/打字 + 当前画布 → 后端。
2. AI 返回 `CocreateResponse`，其中 `scenes.append`（续写）或 `scenes.rewrite{from}`（改写最近若干镜，对应"让它再跳高一点"）。
3. `applyResponse` 把分镜并入 `session.scenes`（append 直接拼接；rewrite 截断到 `from` 再拼新镜）。
4. App 立即播放**本拍新增/改写的分镜**：`append` → `playScenes(from = 原长度)`；`rewrite` → `playScenes(from)`。
5. 底部加 **▶️ 再演一遍** 按钮 → `replayAll`，把整段故事从头演一遍。

> 依赖项（必须一并做，否则 `shapeId` 无法可靠引用）：**后端需要知道画布上已有哪些 shape**。`buildRequest` 附带 `shapes`（id + kind + 当前归一化坐标/颜色/文字的精简清单）；`model.ts` 把该清单拼进 user 文本，并在 prompt 要求"`actions.shapeId` 必须引用清单中的 id"。这同时修复了既有分析报告中的 H2 缺陷。

## 5. 提示词升级（`server/model.ts`）

SYSTEM_PROMPT 改为产出分镜脚本，要点：
- 继续用 ellipse/rectangle 简笔画拼造型、归一化坐标、口语化温暖。
- 新增：用 `scenes.append` 把这一拍的剧情排成**一个或多个分镜**；每镜一句 `narration`；镜内多个角色动作会**同时**发生。
- 跨镜表达互动：把"A 碰到 B 后 B 的反应"拆成相邻两镜（前镜 A `moveTo` B 的位置，后镜 B `disappear`/变化 + A `wobble`）。
- `actions.shapeId` 必须引用"画布已有清单"里的 id（清单随请求给出）。
- 孩子要改上一段时用 `scenes.rewrite.from`。
- 给一个完整 JSON 示例（含 2 个分镜的互动）。

## 7. 错误处理

- 坏 `scenes`/`actions`（缺 `shapeId`、`do` 非法、坐标非数值）：引擎跳过该 action/scene，`console.warn`，不中断整段播放。
- 引用不存在的 `shapeId`：跳过。
- TTS 失败或空：旁白照常在故事区显示，仅无声（沿用现有降级）。
- 播放期间禁用麦克风/打字（`phase==='replaying'/'thinking'`），避免并发改画布。

## 8. 测试

- `applyResponse`：`scenes.append` 拼接、`scenes.rewrite.from` 截断重排、与 story/dialog 互不干扰。
- `playScenes` 纯逻辑：分镜按序、镜内动作集合并行收集、缓动函数边界（0→0、1→1、bounce 末值=1）、`from` 起播。
- `buildRequest`：携带 shapes 精简清单且裁剪体量。
- 引擎对 DOM/Editor 的部分用最小 mock Editor（`animateShape`/`updateShape`/`getShape` 打桩）验证调用序。

## 9. 验收标准

1. 孩子说"小狗去吃骨头"，画面里小狗**走到**骨头处、骨头**消失**、小狗**开心抖一下**，并听到对应旁白——这是一次跨镜互动。
2. 同一分镜内多个元素**同时**动（如太阳升起 + 小鸟飞过），不再逐个串行。
3. 孩子说"让它再跳高一点"，最近一镜被 `rewrite` 重演，前面分镜不变。
4. 点 ▶️ 再演一遍，整段故事从头连贯演出 + 旁白同步。
5. 坏数据不致画布崩溃（既有鲁棒性不退化）。
6. `tsc --noEmit` 通过；`vitest run` 全绿（新增引擎测试在内）。

## 10. 风险与权衡

- **RAF tween 与 tldraw 协作**：`updateShape` 逐帧改 `props.w/h` 性能与撤销栈影响需在引擎里用 `editor.run`/`history` 选项控制（动画帧不进撤销历史）。落地时验证。
- **AI 引用 shapeId 准确度**：依赖第 4 节"画布清单回传"；若仍偶发引用错，引擎跳过即可，不致命。
- **wobble≠真表演**：先满足"看起来活了"的及格线，挤压拉伸留作后续增强位。
