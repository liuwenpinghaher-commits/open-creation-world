# 神笔马良 · 设置中心与家长管理 — 设计文档

> 日期：2026-06-19 ｜ 分支：`feat/magic-brush` ｜ 状态：待评审
> 一句话：在创作伙伴之上加一层**家长门后的设置中心**——系统配置（含密钥/模型可改）+ 家长管理（孩子档案 / 引导偏好 / 内容安全 / 成长报告）。成长报告以教育学金标准 **Learning Stories（学习故事）** 为核心，把已有对话/信号数据变成温暖、强项导向、可分享的叙事。

---

## 1. 背景与目标

当前产品是"支架式创作伙伴"，但所有配置只在 `server/.env`，家长无界面可调；孩子的成长只有冷统计。本设计补齐：
- **可视化配置**：模型/密钥/语音/兑现等都能在界面改（家长门保护）。
- **家长管理**：多孩子档案、按孩子的引导偏好、内容安全、成长报告。
- **循证升级**：成长报告用 Learning Stories 叙事 + Torrance 创造力画像；个性化引导由兴趣画像与年龄/气质驱动。

非目标（本期不做）：屏幕时间/使用时长管理；账号云同步；多设备。

---

## 2. 循证依据（来源）

- **Learning Stories（Te Whāriki / Margaret Carr）**：叙事式、强项导向、记录倾向/兴趣，序列 noticing→recognising→responding→recording→**revisiting**，邀请家人参与。([The Education Hub](https://theeducationhub.org.nz/how-to-use-learning-stories-in-ece-assessment-2/)、[learningstories.help](https://learningstories.help/posts/learning-stories/))
- **Torrance 创造力四维**：fluency 流畅 / flexibility 变通 / originality 独创 / elaboration 精进。([TTCT 综述, Frontiers](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2022.1000385/full))
- **家长侧报告最佳实践**：强项为主、叙事胜于裸数据、给可执行下一步、反焦虑不排名。([Backpack Interactive](https://backpackinteractive.com/resources/articles/education-dashboards-best-practices)、[Famly](https://www.famly.co/us/blog/early-childhood-progress-reports))

---

## 3. 入口与家长门

- 入口：主界面角落不显眼的 ⚙️（孩子不易误触）。
- **家长门**：默认"长按 3 秒 + 一道随机算术（如 7+5=?）"——孩子过不去、家长 2 秒过；家长可在设置里改为 4 位 PIN（`pinHash` 本地存）。
- 门后才是全部"系统配置 + 家长管理"。门状态仅本会话有效，离开设置即重新上锁。

---

## 4. A · 系统配置（服务端可写）

| 组 | 项 |
|---|---|
| 多模态模型 | MODEL_ID、MODEL_BASE_URL、MODEL_API_KEY（掩码 `****last4`、可覆盖）+ **测试连接** |
| 语音 | STT 开关/模型；TTS 开关/音色(Cherry…)/语速/音量；VOICE_API_KEY（掩码可改） |
| 兑现动画 | 总开关；启用哪些行为(fly/grow/spin/hop/walk/bounce/wobble 勾选)；豪华档 AnimatedDrawings 开关 + 服务地址 + 测试 |
| 配置管理 | 恢复默认 / 导出配置(脱敏可选) / 导入配置；当前后端地址只读 |

**解析顺序**：内置默认 ← `server/.env` ← `server/config.json`(运行时写入、gitignore) 覆盖。`partner.ts`/`voice.ts` 读"解析后的配置"而非裸 `process.env`。

---

## 5. B · 孩子档案（多孩子）

- **核心字段**：`id`、emoji 头像、昵称、**年龄**（定难度基线）、createdAt；多孩切换；每孩独立数据/作品/报告。
- **兴趣画像 `interests[]`（核心）**：从 `childSignal`/`dialog` 自动识别反复出现的主题（龙、太空、小动物…），家长可增删 → 驱动个性化引导。
- **学习倾向 `dispositions`（可选）**：好奇 / 坚持 / 勇于尝试 / 爱表达——系统观察累积成**画像**（计数/趋势，非打分），呼应 Learning Stories。
- **当前小目标 `focus`（可选）**：家长/系统设"这阵子重点维度"，联动 C。
- 隐私：档案纯本地（Dexie）。

---

## 6. C · 引导偏好（每孩子）

| 偏好 | 说明 | 接入点 |
|---|---|---|
| 维度权重 `dimensionWeights` | 四维度可加权/置顶（"多练想办法"） | `nextMove` 加权轮换（仍保均衡下限） |
| 激发节奏 `pace` | 每拍都引导 ↔ 多留白 | 控制是否本拍仅反映不提问 |
| 鼓励口吻 `tone` | 温和 ↔ 活泼 | partner prompt |
| 兑现频率 `fulfillFrequency` | 保守 ↔ 大方 | 影响模型是否倾向 fulfill |
| **兴趣驱动 `interestDriven`** | AI 优先从孩子兴趣切入提问 | partner prompt 注入 interests |
| **创造力侧重 `creativityFocus`** | 发散(fluency/flexibility) ↔ 深耕(elaboration/originality) | partner prompt 提问策略 |
| SEL 轻引导 `sel`（可选） | 偶尔引导表达感受/为角色着想 | partner prompt |
| 语言 `language`（可选） | 引导语言/方言/双语 | partner prompt |
| 支架锁定 `lockSupport`（可选） | 默认自适应；可锁固定档 | `nextMove` support |

年龄+气质 → 自动基线；家长微调覆盖。全部"每孩子独立"。

---

## 7. D · 内容安全

- `filterLevel`：标准 / 严格（更保守的话题与用词）。
- `blockedTopics[]`：家长自定义关键词，命中则 AI 温柔转移话题。
- "只鼓励不否定"始终开、不可关。
- 接入：partner prompt 安全段 + 后端对 provoke 的轻量过滤兜底。

---

## 8. E · 成长报告（核心：Learning Stories）

### 8.1 学习故事（核心）
每次创作后由 LLM 后处理把该 session 的 `dialog/signals` 生成一篇**温暖叙事**，结构遵循 noticing→recognising→responding，**原文引用孩子的话**、强项导向：
> "今天小宝画了一条会喷火的龙。我问它住在哪里，他想了想说'火山最深处'。当火山冒烟时，他自己想出办法让龙飞走——这是很棒的解决问题！"

### 8.2 能力画像（核心）
- 四维度趋势（observe/narrative/imagination/problem）。
- **Torrance 创造力画像**：LLM 给每拍孩子产出打标签（fluency/flexibility/originality/elaboration 的轻量代理），跨作品累积成画像。
- dispositions 成长轨迹（来自 B）。

### 8.3 报告形态（核心）
- **回看 revisiting**：和孩子一起重读旧学习故事（自我评估 + 再创作引子）。
- **周报/月报**：高光故事精选 + 一句"**下一步在家可以试试…**"（actionable）。
- **高光时刻**：自动挑"想出新点子 / 自己解决问题"的瞬间。
- **导出**：单篇故事 or 整本"成长故事书" → PDF/图片/文本。
- **反焦虑**：强项为主、不排名、不与他人比、growth area 用温和"下一步"。

### 8.4 家人参与（可选）
家长给某篇学习故事写一句回应/点赞 `familyNote`，孩子下次回看能看到（home link）。

---

## 9. F · 数据与隐私

- 全本地说明（画与对话存本机 IndexedDB；**感知时画面会上传给模型**，明示）。
- 清空：删单个孩子数据 / 删全部作品 / 恢复出厂。
- 导出：某孩子全部作品（图片）+ 成长故事书。
- **隐私模式**：关闭云端感知 → 降级"仅凭语音引导"（不上传画面）。

## 10. 架构与数据流

### 10.1 两类配置
- **服务端配置（含密钥）**：`server/config.ts` 解析 + `server/config.json`(gitignore) 持久化。
  - 端点：`GET /api/config`（**只回掩码**：`apiKeySet:boolean + last4`，绝不回明文）、`POST /api/config`（写，家长门后；密钥字段为空=保持不变，有值=覆盖）、`POST /api/config/test`（用当前/待写配置测连）。
- **家庭配置（孩子/偏好/安全/家长门）**：客户端 Dexie，新表 `profiles`、`familyConfig`、`stories`。

### 10.2 运行时接入（每拍）
App 读"活跃孩子"的 `age + prefs + interests + safety` → 组装 `childContext` 随 `buildRequest` 带给后端：
- `partner.ts` 用 `childContext` 拼**个性化段**（难度/口吻/兴趣/创造力侧重/SEL/语言/安全）。
- `engine.nextMove` 用 `dimensionWeights/lockSupport`。

### 10.3 数据模型（新增/扩展）
```ts
type ServerConfig = { model:{id,baseUrl,apiKeySet:boolean}, voice:{stt,tts,voice,rate,volume,apiKeySet}, fulfill:{enabled,behaviors[],animatedDrawingsUrl} }
type ChildProfile = { id, name, emoji, age, interests:string[], dispositions:Record<string,number>, focus?:GuidanceDimension, createdAt }
type GuidancePrefs = { dimensionWeights:Record<GuidanceDimension,number>, pace:number, tone:'gentle'|'lively', fulfillFrequency:number, interestDriven:boolean, creativityFocus:'diverge'|'deepen', sel:boolean, language?:string, lockSupport?:'auto'|'high'|'normal' }
type ContentSafety = { filterLevel:'standard'|'strict', blockedTopics:string[] }
type ParentGate = { mode:'arith'|'pin', pinHash?:string }
type LearningStory = { id, workId, childId, narrative, highlights:string[], tags:{torrance:Record<string,number>, dispositions:string[]}, createdAt, familyNote? }
```
- 现有 `Work` 增 `childId`；`summary` 扩为"按孩子跨作品聚合"。

## 11. 模块边界（可独立测试）

- `server/config.ts`（纯解析 + 读写）：默认←env←json 合并、掩码、原子写。单测。
- `src/settings/childContext.ts`（纯）：profile+prefs+safety → 传给后端的 childContext。单测。
- `server/personalize.ts`（纯）：childContext → prompt 个性化段。单测。
- `engine.nextMove` 扩 `weights/lockSupport`（纯）。单测。
- `server/story.ts`：session → LearningStory（LLM 后处理 + sanitize）。
- `src/store/profiles.ts`、`familyConfig.ts`（Dexie）。
- UI：设置中心（家长门 → 分组面板）、成长报告（学习故事/趋势/导出）；与现有极简儿童主界面隔离，孩子界面不受影响。

---

## 12. 安全

- 密钥掩码显示、仅家长门后可改；`config.json` gitignore、本地文件权限。
- `/api/config` 写仅限本地；明示"家庭本地自用，勿公网暴露后端"。
- 家长门是 UX 守卫（防孩子误入），非强安全；PIN 仅本地 hash。

---

## 13. 分期

- **P0**：家长门 + 系统配置(模型/语音/兑现, server config 读写+测连) + 孩子档案(基础字段+多孩)。
- **P1**：引导偏好(全量) + 内容安全 → 接 `nextMove`/personalize prompt；childContext 运行时接入。
- **P2**：成长报告 = Learning Stories 生成 + 回看 + 四维/Torrance 画像 + 高光 + 导出。
- **P3**：周报/月报 + 家人参与 + 隐私模式(关闭云端感知) + 配置导入导出 + 兴趣画像自动识别。

---

## 14. 验收

- 家长门：孩子点 ⚙️ 进不去（算术/PIN 拦住）；家长 2 秒进。
- 配置：界面改模型/密钥/音色并"测试连接"通过；重启后端仍生效（config.json 持久）。
- 多孩：切换孩子后，引导难度/偏好/作品/报告随之切换。
- 个性化：设"多练想办法 + 兴趣=恐龙"，真实 qwen 出的激发明显更偏问题解决且从恐龙切入。
- 成长报告：一次创作后生成一篇强项导向的学习故事，含原文引用 + 一句"下一步在家试试"；可导出；可和孩子回看。
- 不破坏现有：孩子主界面与创作主回路不受影响；`tsc/eslint/vitest` 全绿。
