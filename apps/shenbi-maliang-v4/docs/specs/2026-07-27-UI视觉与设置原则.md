# UI 视觉与设置原则（v1.0）

> 服务 v3.1 真源。冻结用户纠偏：**主界面高效简洁、去卡通；设置页给家长用，信息密度要够。**

---

## 1. 受众拆分（别混）

| 界面 | 使用者 | 目标 | 风格 |
|------|--------|------|------|
| **主画布** | 孩子为主、家长陪 | 少挡笔、少装饰、快完成「画→说→听」 | 中性、工具感、低饱和 |
| **设置** | **仅家长** | 配密钥、模型、孩子档案、安全、诊断 | 桌面软件密度，**不要**儿童卡通 |

旧方案写「儿童优先」时，误把 **主路径控件做成圆角黄钮奶黄气泡**——这是「假可爱」，不是高效。  
孩子需要的是 **大点击区 + 少字 + 不挡画**，不是黄色胶囊和装饰标签。

---

## 2. 主界面（强制）

### 要

- 画布占满；顶栏极薄或可隐  
- 底栏：单行输入 + 主操作 + 次要「按住说」（P0）  
- 回复：普通文本条 / 轻边框，**无**暖黄大圆角「对话框贴纸」  
- 色：中性灰底、一色强调（如墨/靛），**禁用**糖果黄、彩虹、emoji 堆砌  
- 字号清晰即可，不靠圆角和阴影「卖萌」  

### 不要

- 奶黄气泡、圆角胶囊 Logo 条、「～」语气装饰当默认  
- 多状态彩点、调试文案常驻  
- 把家长设置做成第二个卡通页  

---

## 3. 设置页（强制 · 回答「为什么不能太简洁」）

**简洁 ≠ 空洞。**  
主界面简洁 = 减干扰；设置简洁若变成「三两个开关」，家长无法完成：

| 设置必须覆盖（分栏） | 说明 |
|----------------------|------|
| **连接** | MODEL_BASE_URL、MODEL_ID、API Key 状态（掩码）、连通测试 |
| **语音** | STT/TTS 开关与音色、回落策略说明 |
| **孩子** | 档案列表、活跃孩子、基础偏好（P1） |
| **安全与门** | 家长门、隐私、内容安全 |
| **关于 / 诊断** | 版本、最近错误、本地方案链接 |

信息架构：**左侧导航 + 右侧表单**（或顶 Tab），桌面 480–720px 宽面板，**密度对齐 Linear/系统偏好设置**，不是大按钮乐园。

家长门：算术/PIN 保留，防止孩子乱改密钥——门后才是密设置。

---

## 4. 与 v3.1 修订

| 原表述 | 修订 |
|--------|------|
| D6「儿童优先」易被理解成卡通 UI | **D6′：主路径低干扰工具感；设置高密度家长工具** |
| UI 线框里的圆角黄钮示意 | 改为中性底栏示意 |
| 「极小家长设置」 | 入口可小；**面板本身不简陋** |

---

## 5. 验收

- 主界面截图：无糖果黄主色、无贴纸感气泡  
- 设置：≥4 个逻辑分区；密钥/模型可配可测  
- 孩子主路径仍 ≤3 步完成「画→问→得到回复」
