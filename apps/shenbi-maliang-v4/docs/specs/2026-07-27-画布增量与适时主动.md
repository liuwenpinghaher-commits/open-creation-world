# 画布增量与适时主动（v1.0）

> 服务 v3.1；补充「持续画 + 持续聊」与「只画不说也互动」。

## 1. 看画管线（每拍邀请时）

```text
L0  邀请门闩：按住说 / 打字 / 适时主动
L1  结构差分（本地签名：增删/原地改）→ summary + addedIds
L2  注意力图：全图 JPEG +（若有新增）新区特写 JPEG +（若有）上一拍全图缩略
L3  VL + sceneNote 文字连续理解
```

**不做默认：** 像素主 diff、SAM/检测、边画边 VL。

## 2. 适时主动（只画不说）

**产品裁决：** 默认可开；**不是**每笔画都说话。

| 参数 | 默认 | 含义 |
|------|------|------|
| `T_DRAW_IDLE_MS` | 3500 | 停笔后多久算「告一段落」 |
| `T_PROACTIVE_COOLDOWN_MS` | 50000 | 两次主动最少间隔 |
| `MIN_NEW_SHAPES` | 1 | 至少新增形状数（或指纹变且面积变大） |
| 允许相位 | idle / sleep / follow_up | 听/想/说/录音中绝不插话 |

流程：画布 document 变更 → 重置停笔计时 → 停满 → 差分够格且过冷却 → 主动一拍（无孩子话语）→ 气泡+TTS → 更新签名/sceneNote → 进 FOLLOW_UP。

**仍安静的情况：** 冷却中、变化太小、正在对话链路、隐私模式可仍主动（不上传则只靠文字——隐私时跳过主动或仅文字；默认有图时主动）。

## 3. 与「无邀请不打扰」关系

- 安静画过程中：**零云端**（只本地计时/差分）。  
- 主动 = **停笔后的软邀请**，等价于系统代点「问马良」，不是边画边评。
