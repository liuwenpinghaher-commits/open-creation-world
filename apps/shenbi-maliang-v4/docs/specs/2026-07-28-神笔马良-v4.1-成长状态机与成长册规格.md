### 1.2 数值边界

```ts
const STRENGTH_MIN = 0
const STRENGTH_MAX = 1
const STRENGTH_INIT = 0.35          // 冷启动：中间略偏低，避免「全满」或「全空」
const EVIDENCE_BOOST = 0.04         // 本拍练到该维：基础增益
const QUALITY_BONUS = 0.02          // 可选：长表达/纠正成功等
const STUCK_PENALTY = 0.01          // 连续 stuck 且该维被练：增益减半，supportBias→high
const DECAY_PER_DAY = 0.005         // 自然衰减：每日对 strength 乘 (1 - d) 的近似用减法
const DECAY_FLOOR = 0.15            // 衰减不低于此（保护「曾经练过」）
const MAX_DELTA_PER_TURN = 0.08     // 单拍单维最大涨幅（防暴涨）
```

**原则：** `strength` 只服务内部策略与温和叙事；**永不**直接展示为「得分 87」。

## 2. 状态机

### 2.1 类型

```ts
type GuidanceDimension =
  | 'observe_express'
  | 'narrative_logic'
  | 'imagination'
  | 'problem_solving'
  // EXT 可选

type DimensionState = {
  childId: string
  dimension: GuidanceDimension
  strength: number          // [0,1]
  evidenceCount: number     // ≥0
  lastEvidenceAt: number    // ms
  supportBias: 'high' | 'normal'
  note: string              // ≤120 字，内部
  updatedAt: number
}

type GrowthEvent = {
  id: string
  childId: string
  workId: string | null
  verb:
    | 'canvas_changed'
    | 'said'
    | 'invited'
    | 'partner_replied'
    | 'proactive_nudge'
    | 'dimension_practiced'
    | 'state_updated'
    | 'parent_viewed_growth'
  object?: string           // 如 workId、utterance 摘要
  context: Record<string, unknown>
  at: number
}
```

### 2.2 冷启动

对每个 `childId`，首次需要状态时：

```text
for d in CORE:
  DimensionState {
    childId, dimension: d,
    strength: STRENGTH_INIT,
    evidenceCount: 0,
    lastEvidenceAt: 0,
    supportBias: 'normal',
    note: '',
    updatedAt: now
  }
```

### 2.3 衰减（读时惰性）

在 **读取** 某维状态做策略或成长册前：

```text
days = floor((now - lastEvidenceAt) / 86400000)   // lastEvidenceAt==0 → 不衰减
if days >= 1:
  strength = max(DECAY_FLOOR, strength - DECAY_PER_DAY * days)
  // 不写 evidenceCount；可写回 store（节流：每天最多一次）
```

### 2.4 本拍更新：`applyPractice`

**输入：** 当前 `DimensionState`、本拍 `PracticeSignal`  
**输出：** 新 `DimensionState`（纯函数，必须单测）

```ts
type PracticeSignal = {
  dimension: GuidanceDimension
  /** 本拍策略是否练此维 */
  practiced: boolean
  /** 孩子 utterance 长度（字） */
  childChars: number
  /** 本地 engagement */
  engagement: 'stuck' | 'normal' | 'flowing'
  /** 是否纠正了马良 / 改口（P1+） */
  revised?: boolean
  /** 是否主动提问（P1+） */
  childAsked?: boolean
  now: number
}
```

```text
function applyPractice(s: DimensionState, sig: PracticeSignal): DimensionState
  if !sig.practiced:
    // 仅可能更新 supportBias（若 stuck 且本拍没练到）
    if sig.engagement == 'stuck':
      return { ...s, supportBias: 'high', updatedAt: sig.now }
    return s

  delta = EVIDENCE_BOOST
  if sig.childChars >= 12: delta += QUALITY_BONUS
  if sig.engagement == 'flowing' && sig.childChars >= 8: delta += QUALITY_BONUS * 0.5
  if sig.engagement == 'stuck': delta = max(0.01, delta * 0.5)

  // P1+ 钩子
  if sig.revised: delta += QUALITY_BONUS
  if sig.childAsked && dimension 可映射 questioning: …（P1）

  delta = min(MAX_DELTA_PER_TURN, delta)
  strength' = clamp(s.strength + delta, STRENGTH_MIN, STRENGTH_MAX)

  supportBias' =
    sig.engagement == 'stuck' ? 'high' :
    sig.engagement == 'flowing' && s.supportBias == 'high' ? 'normal' :
    s.supportBias

  note' = 可选截断：最近一次孩子话 40 字

  return {
    ...s,
    strength: strength',
    evidenceCount: s.evidenceCount + 1,
    lastEvidenceAt: sig.now,
    supportBias: supportBias',
    note: note',
    updatedAt: sig.now
  }
```

```text
function pickFocusDimension(states: DimensionState[], weights?: Record<dim, number>): dim
  // 有效强度 = strength / max(0.01, weight)  — weight 默认 1，家长加权 >1 表示多练
  // 选有效强度最低者；并列时按 CORE 固定序
  // 若 trailing 同维已 ≥2（dimHistory），强制换维（与现 engine 一致）
```

**与现 `nextMove` 关系：**  
- `nextMove` 继续产出 crowd/support；  
- **dimension 优先 `pickFocusDimension(states)`**，再套 forceSwitch / stuck 规则。  
- `dimHistory` 可保留作 forceSwitch 输入，但 **strength 以 DimensionState 为准**。

### 2.6 单测用例（P0 必须全绿）

| # | 场景 | 期望 |
|---|------|------|
| T1 | 冷启动 strength | 全 CORE = 0.35，count=0 |
| T2 | practiced 一次，normal，短句 5 字 | strength ≈ 0.39，count=1 |
| T3 | practiced + 长句 ≥12 | 增益 > T2 |
| T4 | stuck + practiced | 增益 < normal；supportBias=high |
| T5 | 单拍涨幅 | ≤ MAX_DELTA_PER_TURN |
| T6 | 不 practiced | count 不变；stuck 时 bias=high |
| T7 | 衰减 10 天无证据 | strength 下降但不低于 DECAY_FLOOR |
| T8 | pickFocus 弱维 | strength 最低者被选 |
| T9 | 家长 weight 抬高某维 | 该维更易被选（有效强度更低） |

## 3. 事件 → 维度 / 状态

### 3.1 每拍写入顺序（partner 成功路径）

```text
1. said | proactive_nudge
2. canvas_changed（若 delta.changed）
3. dimension_practiced（必有，带 dimension + support）
4. partner_replied
5. applyPractice → state_updated（可合并一条 context）
```

失败：partner 失败则 **不写** 2–5 中依赖成功的项；`said` 可保留（孩子确实说了）。

### 3.2 贴维规则（本拍 `dimension` 从哪来）

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1 | **本地 engine** `nextMove` / `pickFocusDimension` | P0 主权；可测 |
| 2 | 不可用 LLM 事后改维写 strength | 防黑盒；LLM 只润色 line |

可选 P2：LLM 输出 `noticed` 后 **仅写 note**，不改 strength。

### 3.3 各 verb 对成长的影响

| verb | 写 events | 改 strength | 说明 |
|------|-----------|-------------|------|
| `said` | ✅ | 否（间接） | 提供 childChars / 文本 |
| `proactive_nudge` | ✅ | 否 | 记互动；practiced 维仍来自策略 |
| `canvas_changed` | ✅ | 否 | 分析「画说联结」 |
| `invited` | ✅ | 否 | 可选 |
| `dimension_practiced` | ✅ | **是（主）** | 触发 applyPractice |
| `partner_replied` | ✅ | 否 | 回放与提问占比 |
| `state_updated` | ✅ | — | 审计用，已在 apply 后 |
| `parent_viewed_growth` | ✅ | 否 | 分析用 |

### 3.4 `context` 最小字段

**said**

```json
{ "text": "…", "source": "stt|type", "chars": 12 }
```

**dimension_practiced**

```json
{ "dimension": "imagination", "support": "normal|high", "crowd": "open" }
```

**partner_replied**

```json
{ "line": "…", "preferQuestion": false, "proactive": false }
```

**canvas_changed**

```json
{ "added": 1, "removed": 0, "fingerprint": "…", "summary": "…" }
```

### 3.5 dialog 双写

| 存储 | 用途 |
|------|------|
| `works.dialog` | 作品内回放、喂 history |
| `events` | 成长查询、跨作品统计 |

同一拍两边都写；**成长统计只读 events**。  
`works.dimHistory`：可继续 append 供 forceSwitch，**不再当作 strength 真源**。

## 4. 分析指标（可计算）

均基于 `events` + `dimensionStates`，时间窗默认 **7 日**（可设置）。

| 指标 id | 计算 | 用于 |
|---------|------|------|
| `dim_evidence_7d[d]` | count(dimension_practiced where dim=d, 7d) | 哪维练得少 |
| `dim_strength[d]` | 读时衰减后的 strength | 策略 + 叙事 |
| `stuck_rate_7d` | said 中 engagement 需会话侧写入 context 或近似：support high 比例 | 支架 |
| `question_rate_7d` | partner_replied.preferQuestion 为 true 的占比 | 产品健康（少追问） |
| `proactive_count_7d` | proactive_nudge 次数 | 是否打扰 |
| `draw_then_talk_7d` | canvas_changed 后 10min 内有 said 的比例 | 画说联结 |

P0 成长摘要至少用：`dim_evidence` 或 `evidenceCount` + 最近 works。

## 5. 家长叙事模板（不测评）

### 5.1 维度文案映射

| 条件 | 文案模板（示例） |
|------|------------------|
| 7 日 evidence 最高维 | 「最近更常练到「{维名}」」 |
| 7 日 evidence=0 且 strength 偏低 | 「「{维名}」这阵子练得少，画画时可以多聊聊」 |
| supportBias=high 较多 | 「有时需要更简单的小问题带着说」 |
| question_rate > 0.6 | （内部指标，可不展示）「我们会少问一点，多接他的话」 |
| 无任何事件 | 「还没有一起画聊的记录，画两笔问马良即可开始」 |

**禁止模板：**「得分」「等级」「落后」「只有 X 分」。

### 5.2 提高建议（任务卡片）

```text
focusDim = pickFocusDimension(states) 或 7 日 evidence 最少维
建议 = PLAYBOOK[focusDim].example 改写成家长口吻一条
例如：观察维 → 「下次可以让他数一数画里有几处颜色」
```

P0：1 条建议即可。  
P1：本周焦点维可与家长 weights 对齐。

## 6. 成长册信息架构（三屏）

入口：**设置 → 孩子 →「成长册」** 或设置导航新增 **「成长」**（P0 二选一，推荐导航 **成长**）。

### 6.1 屏 A · 总览

```text
┌ 成长册 ────────────────────┐
│ 孩子：[名 ▼]    近 7 日     │
│                            │
│ 一句话：{narrativeHeadline} │
│                            │
│ 四维（过程热度，非分数）      │
│  观察表达  ████░░  较常练   │
│  叙事逻辑  ██░░░░  可多练   │
│  想象延展  ███░░░           │
│  解决问题  █░░░░░           │
│  （条仅为相对热度可视化）     │
│                            │
│ 建议试试                    │
│  「{oneTip}」               │
│                            │
│ [最近作品 →]                │
└────────────────────────────┘
```

| 字段 | 来源 |
|------|------|
| narrativeHeadline | 5.1 模板 |
| 四维条 | strength 或 7d evidence **归一化相对长度**（标注「非评分」） |
| oneTip | 5.2 |
| 空态 | 「画两笔，问马良，这里会出现痕迹」 |

### 6.2 屏 B · 作品时间线

```text
┌ 最近作品 ──────────────────┐
│ · 3/28 未命名画  聊 5 轮    │
│   维：想象×2 观察×1         │
│ · 3/27 …                    │
│                            │
│ 点进：dialog 摘要只读       │
│ （不在此改密钥）             │
└────────────────────────────┘
```

| 字段 | 来源 |
|------|------|
| 作品列表 | works by childId, updatedAt |
| 维次数 | events dimension_practiced group by workId |
| 空态 | 「还没有作品会话」 |

### 6.3 屏 C · 建议与设置（可与 A 合并 P0）

```text
┌ 培养偏好 ──────────────────┐
│ 本周更想练：[多选维/权重]   │  → guidance weights
│ 少主动打扰：[用互动设置]    │  → 链到 systemPrefs
│                            │
│ 导出成长数据（P1）          │
└────────────────────────────┘
```

P0：**屏 A 必做**；屏 B 可缩成 A 底部列表；屏 C 可只做「打开互动设置」链接。

### 6.4 交互与权限

- 成长册在 **家长门之后**。  
- 打开时写 `parent_viewed_growth`。  
- 孩子主画布 **不出现** 图表。
