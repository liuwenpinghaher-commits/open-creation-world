## 0. 一句话与阅读地图

### 0.1 一句话

> **神笔马良是家庭侧的「素质成长教练」：在画与聊中采集过程证据，维护孩子可解释的能力状态，用支架式互动推动提高，并让家长看见变化。**  
> **画（tldraw）= 主练习场；说/听 = 表达通道；VL/LLM = 语义理解与润色；成长核心 = 本仓自研。**

## 1. 为何重定 v4

### 1.1 用户收敛（2026-07-27～28）

1. 画板部分可接受；**语音自研管线与「记忆」形态不对**，继续修成本高。  
2. 需要成熟通用能力时，倾向借运行时/标准，而不是无限加 glue。  
3. **真正重点不是语音本身**，而是对小孩做 **AI 时代素质模型的培养**：**跟踪 · 分析 · 提高**。  
4. 深度调研结论：无「画板+中文伙伴+支架+抗误打断」开箱整包；v3.1 拼法在**旧目标框**内仍是最佳拼接——但 **未覆盖素质成长中心**。  
5. 用户指令：**重定 v4 真源**。

### 1.2 v3.1 保留 / 推翻

| 保留 | 推翻或降权 |
|------|------------|
| 不替画、不测评排名、支架思想 | **P0 唯一验收 = 1 分钟听到回复**（降为交互子验收） |
| tldraw 画板 + 截图范式 | 「产品 = 画板伙伴」的中心表述 |
| 云中文 STT/TTS/VL 零件优先 | 自研串行语音管线必须永远主路径（可旁路成熟运行时） |
| 本地 engine 策略主权 | dialog-only 记忆当成长系统 |
| 门闩公式思想 (G1∧G2)∨G3 | P0 堆满完整 barge 仍非成长主线 |
| UI 工具感 + 家长高密度设置 | 设置里只有连接、没有成长参数/档案叙事 |

### 1.3 失败模式（防再犯）

| 失败 | 根因 | v4 对策 |
|------|------|---------|
| 做完很会聊，家长不知孩子长了啥 | 无证据层与状态层 | §3–5 强制 |
| 为语音丝滑换 Agent 壳 | 中心错位 | V4-D1/D9 |
| 做成网校 Moodle | 错用 LMS | 禁止 LMS 当主 UI |
| 做成能力排行 | 误用测评 | V4-D5/D7 |
| 又堆 God-App | 无边界 | V4-D13 + §7 |

## 2. 三层架构（全文核心）

```text
┌────────────────────────────────────────────────────────────┐
│  C · 素质成长核心（本仓自研 · 产品灵魂）                      │
│  素质模型 · 学习者状态 · 策略 engine · 提高建议 · 成长册叙事   │
└──────────────────────────▲─────────────────────────────────┘
                           │ 读状态 / 写策略标签
┌──────────────────────────┴─────────────────────────────────┐
│  B · 证据与记录（标准可借 · 存储可成熟）                        │
│  学习事件（xAPI 风格）· 作品会话 · 档案 · 可选向量短事实        │
└──────────────────────────▲─────────────────────────────────┘
                           │ 事件写入
┌──────────────────────────┴─────────────────────────────────┐
│  A · 交互传感器（成熟零件 + 薄胶水）                            │
│  画：tldraw · 说听：云直连或 LiveKit/Pipecat 旁路 · 看画：VL   │
│  UI：Kid 主路径 + 家长设置/成长册                              │
└────────────────────────────────────────────────────────────┘
```

### 2.1 层职责

| 层 | 必须交付 | 禁止承担 |
|----|----------|----------|
| **C** | 维度定义、状态更新规则、下一拍策略、家长可读提高建议 | 原始 WebRTC、ASR 实现细节 |
| **B** | 事件持久化、按孩/按作品查询、导出 | 代替教育学策略 |
| **A** | 低摩擦画与聊、可靠采证 | 决定「练哪一维」；不替画 |

### 2.2 数据流（一拍）

```text
[画/说] → A 采集（可选截图、转写）
       → B 写事件：actor, verb, object, context(维度/增量/…)
       → C 更新学习者状态
       → C 产出 moveHint / 是否提问 / 支架
       → A 伙伴润色（LLM）+ 播报
       → B 写伙伴回复事件 + sceneNote
       → （家长）成长册读 B+C 聚合
```

**无事件写入的「成功回复」在 v4 算 partial，不算成长路径完成。**

## 3. 素质模型（跟踪什么）

### 3.1 核心四维（继承并升格为状态主键）

| ID | 名称 | 过程表现（证据方向） |
|----|------|----------------------|
| `observe_express` | 观察与表达 | 命名细节、颜色/数量/位置、可纠正的描述 |
| `narrative_logic` | 叙事逻辑 | 因果、顺序、前后一致 |
| `imagination` | 想象延展 | 如果…、非常规联想 |
| `problem_solving` | 解决问题 | 面对障碍提办法、不直接要答案 |

### 3.2 AI 时代扩展维（v4 新增 · 可分期启用）

| ID | 名称 | 过程表现 |
|----|------|----------|
| `questioning` | 提问与好奇 | 主动提问、追问、澄清 |
| `revise_with_other` | 修正与共创 | 听建议后改画/改说法；纠正马良 |
| `human_ai_tandem` | 人机协作意识 | 会请马良看画、会拒绝错误猜测 |

P0 可只落四维；扩展维 P1 起写事件，P2 进状态与成长册。

### 3.3 状态表示（禁止排名）

每个孩子、每个维度维护：

```ts
type DimensionState = {
  dimension: string
  /** 0–1 过程热度/熟练趋势，仅内部与温和叙事用，不展示为「得分榜」 */
  strength: number
  evidenceCount: number
  lastEvidenceAt: number
  /** 最近支架需求 */
  supportBias: 'high' | 'normal'
  /** 一句话内部笔记 */
  note?: string
}
```

家长侧只呈现：

- 「最近更常…」  
- 「可以试试…」  
- 作品时间线与精彩片段  

**禁止：** 总分排行、年级对比、红灯羞辱。

## 4. 证据层（记忆的正确形态）

### 4.1 原则

- **记忆 = 可查询的成长证据 + 当前状态**，不是 Agent 工作流日记。  
- 每条证据尽量 **xAPI 风格**：`actor` · `verb` · `object` · `context` · `timestamp`。  
- 作品 `workId` 是第一外键；孩子 `childId` 是第二外键。

### 4.2 核心事件类型（最小集）

| verb | 何时 | context 关键字段 |
|------|------|------------------|
| `drew` / `canvas_changed` | 画布结构变化（可合并节流） | fingerprint, added, removed |
| `said` | 孩子话（转写或打字） | text, source(stt\|type) |
| `invited` | 明确邀请（按住/发送/唤醒） | channel |
| `partner_replied` | 马良回复 | line, move, preferQuestion |
| `proactive_nudge` | 停笔主动 | reason |
| `dimension_practiced` | 本拍策略维 | dimension, support |
| `state_updated` | 状态变更 | before/after 摘要 |
| `parent_viewed_growth` | 家长打开成长册 | — |

### 4.3 存储选型（v4）

| 阶段 | 存储 | 说明 |
|------|------|------|
| **P0** | 本机 **Dexie** 扩表：`events` + `dimensionStates` + 现有 works/family | 家庭单机足够；实现快 |
| **P1** | 事件 schema 对齐 xAPI 字段；可导出 JSON | 为分析/备份 |
| **P2+** | 可选 Postgres / 小型 LRS；可选 Mem0 **仅**跨画短事实 | 不上中台替换作品 transcript |

### 4.4 sceneNote

- 继续保留 **画布语义连续**（马良对这幅画的理解）。  
- 它是 **object 级笔记**，不是素质状态本身。  
- 状态更新可参考 sceneNote，但 **维度 strength 必须以事件规则为主**（可测）。

## 5. 跟踪 · 分析 · 提高

### 5.1 跟踪（Track）

- 每拍必写：`said` 或 `proactive` + `partner_replied` + `dimension_practiced`。  
- 画增量：`canvas_changed`（与现有 `canvasDelta` 对齐）。  
- 会话：work 级 dialog 仍存，便于回放。

### 5.2 分析（Analyze）

本地可计算（无需重模型）：

| 指标 | 用途 |
|------|------|
| 各维 `evidenceCount` / 近 7 日频次 | 哪维练得少 |
| `supportBias` 偏 high 的比例 | 是否常卡住 |
| 提问轮占比 | 是否过追问（产品健康） |
| 主动停笔次数 | 互动是否打扰 |
| 画增量后是否有语言输出 | 画说联结 |

可选 LLM：**仅生成家长叙事文案**，不直接改 strength（防黑盒乱改状态）。

### 5.3 提高（Improve）

```text
状态（哪维弱 / 是否 stuck）
  → nextMove / preferQuestion / support
  → 伙伴一拍
  → 新证据
  → 状态更新
```

家长提高入口（设置或成长册）：

- 本周焦点维（可选加权，继承 guidance weights）  
- 「下次画画可以试…」任务卡片（非作业系统）

### 5.4 与「不测评」的边界

| 可以 | 不可以 |
|------|--------|
| 过程热度、趋势箭头 | 百分制成绩、班级排名 |
| 「更会讲顺序了」 | 「叙事逻辑 D 级」 |
| 建议练习 | 强制打卡羞辱 |

## 6. 交互传感器（画 · 说 · 看画）

### 6.1 画（A1）

- **继续 tldraw**（make-real 改造仓）。  
- 默认画笔、粗细颜色、全图预览、新画清空 = 交互体验要求（已有方向保留）。  
- 结构增量 `canvasDelta`：**证据与按需看画的输入**。

### 6.2 说 / 听（A2）

| 阶段 | 策略 |
|------|------|
| **默认** | 云 STT/TTS 直连（百炼）；按住说可用；设置可调 |
| **升级（可选）** | LiveKit Agents 或 Pipecat **旁路**：只提供 partial/final/speech 事件；**成长核心与画板仍在本仓** |
| **禁止** | OpenHuman/Hermes 当主程序；Realtime 黑盒替换策略层 |

邀请纪律（继承并强化）：

- 无邀请默认不 ASR 上云（适时主动 = 产品定义的软邀请，须写 `proactive_nudge` 事件）。  
- 人设：**接话为主，提问克制**（约每 N 轮或 stuck 时问）。

### 6.3 看画（A3）

```text
if privacy: 无图
else if !canvasChanged && hasSceneNote: 可跳过 VL，文本伙伴 + 状态策略
else: 小图 VL（可选特写）；默认不传上一帧大图
```

OCR **不作**主看画引擎。

### 6.4 伙伴契约（最小）

```ts
// 请求（逻辑）
{
  utterance, image?, detail?, history?,
  moveHint?, sceneNote?, canvasDeltaSummary?,
  preferQuestion?, childStateSummary?, // v4 新增：状态摘要供润色
  proactive?
}
// 响应
{ line, noticed? }
```

`line` 只给孩子听；`noticed`/状态更新走 B/C。

## 9. UI 原则（继承 + 成长入口）

### 9.1 主界面（孩子）

- 画布 ≥80%；工具感；语音主路径；打字折叠。  
- **不**堆成长图表在画布上。

### 9.2 家长

- 设置：连接 / 语音 / **互动** / 孩子 / 安全 / 关于（已有方向）。

  - 作品时间线  
  - 维度温和叙事  
  - 建议试试  
- 信息密度对齐桌面设置，不卡通假简化。
