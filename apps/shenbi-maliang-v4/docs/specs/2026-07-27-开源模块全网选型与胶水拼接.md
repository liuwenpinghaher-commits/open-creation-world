# 开源模块全网选型与胶水拼接（v1.0）

> 日期：2026-07-27  
> 状态：调研附录 · 服务 [v3.1 设计真源](./2026-07-27-神笔马良-v3-make-real底座-design.md)  
> 目标：**能拼就拼、少自研**；你做胶水，不从零造零件。  
> 方法：按 v3.1 §2 模块全网检索；标注 **主推 / 备选 / 勿用** 与胶水工作量。

---

## 0. 先泼冷水（诚实）

**全网没有**「儿童简笔画 + 中文语音伙伴 + 素质支架 + 抗误打断」的开箱整包。

你能拼的是：

| 层 | 现实 |
|----|------|
| 零件 | 大量成熟开源 / 云 API |
| 管道 | Pipecat / LiveKit 等「语音 Agent 框架」 |
| 画布+看图 | make-real / tldraw |
| **产品语义** | 必须自己写薄胶水（邀请节奏、中文人设、不生成 HTML、儿童 UI） |

胶水的本质不是「再造 ASR」，而是：

```text
画布事件 + 麦事件 + 云/本地服务  →  马良一拍（截图 + 一句支架话 + 播报）
```

## 1. 推荐总装（家庭自用 · 最少自研）

### 1.1 主推拼法（「薄胶水」）

```text
┌─────────────────────────────────────────────────────────┐
│  壳：make-real-starter（Next + tldraw）                   │
│  你改：按钮=问马良；输出=line；儿童 UI；禁 HTML Preview     │
└───────────────────────────┬─────────────────────────────┘
                            │ HTTP
┌───────────────────────────▼─────────────────────────────┐
│  云（你已有百炼/兼容）——胶水最省                           │
│  · VL：qwen-vl-max（看画）                                 │
│  · STT：qwen3-asr / Fun-ASR 云端                           │
│  · TTS：qwen-tts                                           │
└─────────────────────────────────────────────────────────┘

P1+ 再插（仍是零件，不是换壳）：
  · 唤醒：Porcupine 或 sherpa-onnx KWS（本机）
  · VAD：@ricky0123/vad-web
  · 存盘：Dexie
  · 动画糖：Animated Drawings（独立 Python，可选）
```

| 你要写的胶水（薄） | 不要从零写 |
|--------------------|------------|
| 截图→`/api/partner` 契约 | 画布引擎 |
| 按住说→音频 blob→STT | ASR 模型 |
| `line`→TTS 播放器 | TTS 模型 |
| 儿童条 UI | 无限画布 SDK |
| （P1）KWS 回调进会话 | 唤醒训练框架核心 |
| （P2）VAD 帧 + 门闩几行 | 神经网络 VAD |

**工作量直觉：** 零件全用现成，**产品语义胶水约数天～两周**（P0），不是数月重写。

### 1.2 备选拼法（「语音管道外包」）

若你强烈不想管 STT/TTS/打断管道：

```text
画布仍 = make-real 前端
语音管道 = Pipecat（Python）只吐 partial/final/speech 事件
本仓仍拥有：引导 prompt、截图时机、dialog、儿童 UI
```

| 优点 | 代价 |
|------|------|
| barge-in、流式、多服务适配器现成 | 多一个 Python 进程；运维重 |
| 换 Deepgram/本地 FunASR 较容易 | **极易做成「电话 Agent」**，偏离画板伙伴 |

**裁决（与 v3.1 一致）：** 家庭 P0 **先不主用** Pipecat；云 STT/TTS 直连更省。仅当直连体感不够再旁路。

### 1.3 明确不推荐的「整包」

| 项目 | 为何不整包当底座 |
|------|------------------|
| Open WebUI / LibreChat | 聊天壳，无儿童画板主路径 |
| Hermes / OpenClaw | 开发者 Agent，工具面过大 |
| LiveKit Agents 默认栈 | 过重，房间/多人模型不适合「一娃一纸」 |
| 纯 Excalidraw 换掉 make-real | 手绘好，但「截图→多模态」样板与动画 API 弱于 tldraw 路径 |
| 创造世界旧仓 | 体感债重；只当文案/策略参考 |

## 2. 分模块选型卡（全网结论）

图例：⭐ 主推 · ◎ 备选 · ✕ 勿作主路径

### M1 画布 / 工程壳

| 候选 | 结论 | 许可 | 胶水 |
|------|------|------|------|
| ⭐ **tldraw/make-real-starter** | 已选底座；截图+React 最贴 | AGPL-3.0 | 改 prompt/按钮/去掉 HTML |
| ◎ tldraw SDK 裸接 | 更干净但丢 starter 样板 | 商用需核 SDK | 自写 export 几页 |
| ◎ Excalidraw | MIT、涂鸦感强 | MIT | 需自写截图→VL；动画弱 |
| ✕ fabric.js / 自写 canvas | 从零感强 | — | 违背「不想从头」 |

**拼接建议：** 维持 make-real 仓；**只改语义**，不换画布库。

---

### M2 截图画 → 多模态

| 候选 | 结论 |
|------|------|
| ⭐ make-real 的 `toImage` / export 范式 | 业界标杆写法 |
| ◎ SawyerHood/draw-a-ui 等仿品 | 同源思想，维护不如官方 starter |

**拼接建议：** 整页笔触导出 JPEG → 与 utterance 一并 POST（已在方案里）。

---

### M3 多模态「脑」（看画+聊）

| 候选 | 结论 | 胶水 |
|------|------|------|
| ⭐ **云 VL（qwen-vl-max 等）** OpenAI 兼容 | 家庭已通、中文强 | 一条 `/api/partner` |
| ◎ OpenAI GPT-4o / 其他 VL | 可插拔 | 换 baseUrl/model |
| ✕ 本地 VL 作 P0 | 体量大、延迟不稳 | 后期可选 |

**拼接建议：** 不引入 LangChain 全家桶；**10～30 行 fetch + system prompt** 即可。  
策略 engine 可后加，不挡胶水。

---

### M4 听懂 STT（中文）

| 候选 | 结论 | 说明 |
|------|------|------|
| ⭐ **云 ASR（百炼 Fun-ASR / qwen3-asr）** | **胶水最少** | 中文准；你已验证 |
| ◎ **FunASR** 本地/服务 | 中文开源最强档之一 | 比 Whisper 中文 CER 明显更好；需 Python 服务 |
| ◎ faster-whisper | 英语/多语强 | **中文弱于 FunASR**，不优先 |
| ◎ sherpa-onnx | 端侧流式+KWS 全家桶 | 本机部署胶水中等 |
| ✕ Chrome Web Speech 当主路径 | 中文误听多 | 仅回落 |

**拼接建议 P0：** 录音 blob → 现成云 STT API（几乎零模型工程）。  
**想离线再：** FunASR 或 sherpa-onnx 起一个本地服务，前端仍只 POST 音频。

---

### M5 说话 TTS

| 候选 | 结论 |
|------|------|
| ⭐ **云 TTS（qwen-tts）** | 与现网一致，胶水最少 |
| ◎ CosyVoice / Qwen3-TTS 开源 | 中文质量高，但要 GPU/服务 |
| ◎ Edge/浏览器 speechSynthesis | 免费回落，音色一般 |
| ✕ 自训练音色 | 完全不必 |

**拼接建议：** P0 云 TTS；失败再 `speechSynthesis`。

---

### M6 浏览器回落

| 候选 | 结论 |
|------|------|
| ⭐ Web Speech API | 零依赖回落 |
| — | 不可当中文主识别 |

---

### M7 唤醒「马良」

| 候选 | 结论 | 浏览器 | 中文自定义 |
|------|------|--------|------------|
| ⭐ **Picovoice Porcupine** | 方案已定；Web WASM 成熟 | ✅ | 支持（密钥/词） |
| ◎ **sherpa-onnx KWS** | 开源端侧 KWS+ASR 一体 | 需查 wasm 绑定 | 中文友好 |
| ◎ openWakeWord | 开源训练唤醒 | **官方无完整浏览器路线** | 偏 Python/HA |
| ✕ 仅云 ASR 一直听 | 费钱隐私差 | — | 违背休眠 |

**拼接建议：**  
- 要快：Porcupine + access key（家庭可接受）。  
- 要纯开源本机：评估 **sherpa-onnx KWS** 作旁路进程，浏览器 WebSocket 收「检测到马良」。

---

### M8 / M9 人声 VAD（打断 G1）

| 候选 | 结论 |
|------|------|
| ⭐ **@ricky0123/vad-web**（Silero ONNX） | 浏览器 VAD 事实标准；几行回调 |
| ◎ TEN VAD | 宣称更轻更准；可 A/B |
| ◎ Picovoice Cobra | 与 Porcupine 同厂 |
| ✕ 纯 WebRTC 能量 VAD 当 hard 门闩 | 误报多 |

**拼接建议：** `npm i @ricky0123/vad-web` → `onSpeechStart/End` → 你的 barge 状态机（公式仍用本仓几行）。

---

### M11 AEC

| 候选 | 结论 |
|------|------|
| ⭐ `getUserMedia({ echoCancellation, noiseSuppression, autoGainControl })` | 零库 |

---

### M12 / M13 本地记忆

| 候选 | 结论 |
|------|------|
| ⭐ **Dexie.js** | IndexedDB 胶水最少；适合 works/family |
| ◎ localforage | 更简单，查询弱 |
| ◎ RxDB / Electric | 过重 |
| ✕ Mem0 当 P0 会话层 | 杀鸡牛刀 |

**拼接建议：** `dexie` 两张表：`works`、`profiles`；dialog 数组截断存储。

---

### M14 长期记忆（可选）

| 候选 | 结论 |
|------|------|
| ◎ Mem0 open core | 仅当 notes[] 不够 |
| ✕ 一上来图数据库 | 不做 |

---

### M15 / M16 引导策略

| 候选 | 结论 |
|------|------|
| ⭐ **本仓薄模块**（几十～两百行 engine + JSON PLAYBOOK） | 无现成「儿童 PEER 引擎」开源产品 |
| ◎ 旧仓 `guidance/*` 思想迁移 | 抄逻辑不抄 App |
| ✕ 纯 LLM 自选维度 | 易跑偏、不可测 |

**拼接建议：** 这是**唯一必须自研的小核**；不要幻想 npm 一个 `peer-crowd`。

---

### M17 / M18 画活（糖）

| 候选 | 结论 |
|------|------|
| ⭐ 本仓对 tldraw shape 做 CSS/矩阵 tween | 任意涂鸦都能动 |
| ◎ **Meta AnimatedDrawings** | 儿童**人形**绑骨；MIT；需 Python/检测栈 |
| ✕ AI 坐标 addShapes 主链 | 风格两张皮 |

**拼接建议：** P0 不做；P3 再 `docker` 起 AD 服务，前端丢 PNG 收人形动画。

---

### M20 实时语音整管道

| 候选 | 结论 |
|------|------|
| ◎ **Pipecat** | 最佳「语音胶水框架」；68+ 集成；**勿当 UI 壳** |
| ◎ LiveKit Agents | 强 WebRTC 房间；家用过重 |
| ✕ 用它们重写画板路由 | 架构倒置 |

**拼接建议：** 默认不上；若上：

```text
Pipecat ──partial/final/speech_*──► 神笔 Web
神笔 Web ──截图+引导──► VL
```

---

### M21 Agent 壳

| 候选 | 结论 |
|------|------|
| ✕ Hermes / OpenClaw / 通用 Coding Agent | 禁止当儿童主程序 |

## 5. 最终推荐句（给你拍板）

> **最佳「拼接」不是再找一个神笔 monorepo，而是：**  
> **make-real-starter（壳）+ 百炼 VL/STT/TTS（耳眼嘴）+ Dexie（记）+ Porcupine（醒）+ ricky0123/vad（听人声）+ 本仓薄胶水（邀请/支架/儿童 UI）。**  
> **引导 engine 小、自研；语音管道能云则云；Pipecat/FunASR/AD 按需侧挂。**

这与 v3.1 §2 一致，并补上了全网对比后的 **主推/备选** 理由。
